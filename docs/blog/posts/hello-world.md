# 从第一篇笔记开始

最有用的笔记，往往来自一个真实的问题。这是一篇示例文章，用来展示博客的摘要、日期、分类和正文排版。

<!-- more -->

## 为什么记录

解决一个问题之后，很容易只记得结果，忘记中间的判断。写下来，可以让未来的自己少走一遍弯路。

一篇笔记不必很长，但应该回答三个问题：当时遇到了什么、尝试了哪些方法、最后如何确认结果。

## 给笔记一个简单结构

```markdown
# 问题标题

## 背景
当前环境和想要完成的事情。

## 过程
尝试的方法、关键命令和观察到的现象。

## 结果
最终方案、验证方式和适用范围。
```

!!! note "写给未来的自己"
    记录命令时，也写下它为什么有用。上下文比一行孤立的命令更容易复用。

## 从一个小问题开始

选择今天刚解决的一个问题，留下最短但完整的记录。之后再补充链接、示例和新的理解。
