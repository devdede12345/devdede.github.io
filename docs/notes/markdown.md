# Markdown 写作

所有内容都保存在 Markdown 文件中，可以使用任意文本编辑器修改。

## 标题与链接

每页保留一个一级标题，使用二、三级标题组织章节。章节会自动出现在右侧目录中。

```markdown
# 页面标题
## 章节
### 小节
[知识库首页](index.md)
```

站内链接优先指向源 Markdown 文件，构建时会自动转换成网站路径。

## 代码块

在代码块起始处注明语言，即可获得语法高亮和复制按钮。

````markdown
```python
def hello(name):
    return f"Hello, {name}!"
```
````

## 提示框

```markdown
!!! tip "小提示"
    在这里补充读者需要知道的信息。
```

!!! tip "小提示"
    提示框适合补充背景、前置条件或容易忽略的细节。

## 添加文章

在 `docs/blog/posts/` 新建 `.md` 文件，并在文件顶部添加日期与分类。文章会自动进入列表，无需修改导航配置。

```yaml
---
date: 2026-10-09
categories:
  - 学习笔记
slug: my-first-note
---
```

在摘要之后添加 `<!-- more -->`，后续内容会只在文章详情页展开。
