# zyBooks 8：回溯与全排列

根据 `8.pdf` 的 §8.8（PDF 第 27–39 页）与 §8.14（第 74–77 页，资料中标为 Optional）整理。以下示例为重新编写。

## 1. 从一条路径变成一棵选择树

**Permutation**: 排列；顺序不同，结果就不同。三个不同字母 abc 的排列为 abc、acb、bac、bca、cab、cba。

先选第一个字母，再从剩下两个中选第二个，最后放入最后一个：3×2×1=6 种。

```text
空前缀
├─ a → ab → abc
│     ac → acb
├─ b → ba → bac
│     bc → bca
└─ c → ca → cab
      cb → cba
```

## 2. 每次调用保存什么

一种写法传递 `prefix` 和 `remaining`：前者保存已做的选择，后者保存还能使用的字符。每一层选一个字符加入前缀，剩余字符数减一，直到为空，输出完整结果。

下面使用原地交换，避免每个分支复制整个剩余集合：

```java
static void permutations(char[] a, int start) {
    if (start == a.length) {
        System.out.println(new String(a));
        return;
    }
    for (int i = start; i < a.length; i++) {
        char saved = a[start];
        a[start] = a[i];
        a[i] = saved;

        permutations(a, start + 1);

        saved = a[start];
        a[start] = a[i];
        a[i] = saved; // 撤销这一次选择
    }
}
```

初始调用 `permutations("abc".toCharArray(), 0)`。a 必须非 null；start 初始为 0。空数组会输出一个空排列。

**Backtracking**: 做选择 → 递归探索 → 撤销选择 → 尝试下一个选择。撤销后，下一分支才能从与当前分支相同的起点开始。

!!! warning "不要漏掉撤销"

    如果各层共享可变数组或列表，子调用返回不代表对象内容自动恢复。只有局部变量的调用状态得到恢复，对同一个数组做的修改仍会保留，必须显式撤销。

## 3. 购物袋：排列不等于组合

资料用购物袋例子：从 N 个物品中选 k 个，逐个放入袋子，再逐个撤销。若把装入顺序视为不同结果，数量为：

$$
P(N,k)=\frac{N!}{(N-k)!}
$$

例如从 4 个不同物品中选 3 个，枚举装入顺序会产生 24 种。若只关心最终买了哪些物品，不区分顺序，组合数是 4，不能把两种计数混淆。

列表实现通常把一个物品从 remaining 移至 bag，递归后在原索引插回 remaining，并从 bag 末尾移除。恢复顺序也重要，否则会影响下一分支的选择。

## 4. 城市路径也是同一棵选择树

资料的城市路径例子每层选择下一个尚未访问的城市，所有城市都选完时，累计相邻城市的距离。路径状态与未访问集合的角色，分别对应前面的 prefix 和 remaining。

该例允许任意城市作为起点，并未强制最后返回起点，因此不能自行多加一段“最后城市 → 起点”的距离。若要解决完整旅行商回路问题，需要明确固定起点、回程与最短路径等额外要求。

回溯也能枚举子集：对每件物品分成“选”和“不选”两支，可有 2ᴺ 个叶节点；全排列每层从剩余元素选择，叶节点是 N!。两者都可用递归，但选择规则和结果数量不同。

## 5. 成本分析

N 个不同字符有 N! 个结果。仅把每个长度为 N 的结果完整打印，就需要 Θ(N·N!) 的字符输出工作；上面的算法时间在常用字符输出模型下也是 Θ(N·N!)。

递归深度只有 N，不能因此把总调用数判成 N。时间统计所有分支，栈空间统计同一时刻仍未返回的路径。

上面实现修改原数组、不保存所有输出，额外调用栈为 Θ(N)，一次构造输出字符串也需 Θ(N) 空间。若收集全部结果，存储结果本身需 Θ(N·N!) 空间。

如果输入有重复字符，例如 aab，这段代码会重复打印同一个文字排列，因为它区分的是字符所在位置。去重需要额外策略。

## 自测

??? question "1. 把 for 循环倒着遍历，排列的数量改变吗？"

    不改变，只改变探索和输出的顺序。

??? question "2. 三个不同字符只有 3 层递归，为什么输出有 6 个？"

    深度表示一条路径做多少次选择，叶节点数表示所有完整选择的数量。第 1 层有 3 种选择，第 2 层每条有 2 种，第 3 层每条有 1 种。
