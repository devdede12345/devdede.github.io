# 基础排序：选择、插入与冒泡

根据 `9.pdf` §9.1–9.4（PDF 第 1–17 页）整理。下面方法放在类中使用，a 非 null；代码为重新编写。

## 1. Selection Sort

**Selection Sort**: 每轮从未排序部分找到最小值，交换到该部分的开头。

**Invariant**: 第 i 轮开始时，`[0,i)` 已放好最小的 i 个元素；第 i 轮结束时位置 i 也确定。

以 `[29,10,14,37,13]` 为例，表中是一整轮之后的状态：

| i | 找到的最小值 | 交换后 |
|---|---|---|
| 0 | 10 | `[10,29,14,37,13]` |
| 1 | 13 | `[10,13,14,37,29]` |
| 2 | 14 | `[10,13,14,37,29]` |
| 3 | 29 | `[10,13,14,29,37]` |

```java
static void selectionSort(int[] a) {
    for (int i = 0; i < a.length - 1; i++) {
        int min = i;
        for (int j = i + 1; j < a.length; j++) {
            if (a[j] < a[min]) {
                min = j;
            }
        }
        if (min != i) {
            int saved = a[i];
            a[i] = a[min];
            a[min] = saved;
        }
    }
}
```

无论是否已排序，比较次数均为 $N(N-1)/2$，时间 Θ(N²)。真正交换最多 N−1 次；“比较次数平方级”不代表“交换次数也平方级”。额外空间 Θ(1)。

通常不稳定：对 `[2_A,2_B,1]`，第一轮把 1 与 2_A 交换，得到 `[1,2_B,2_A]`，相等键的原顺序被颠倒。

## 2. Insertion Sort

**Insertion Sort**: 左边维护有序区，把右边的下一个元素插入正确位置，如同整理手中的扑克牌。

**Invariant**: 处理 i 之前 `[0,i)` 有序；处理完成后 `[0,i]` 有序，但它们不一定已在最终位置，之后可能整体右移。

| i | 当前元素 | 一整轮后 |
|---|---|---|
| 初始 | — | `[29,10,14,37,13]` |
| 1 | 10 | `[10,29,14,37,13]` |
| 2 | 14 | `[10,14,29,37,13]` |
| 3 | 37 | `[10,14,29,37,13]` |
| 4 | 13 | `[10,13,14,29,37]` |

```java
static void insertionSort(int[] a) {
    for (int i = 1; i < a.length; i++) {
        int value = a[i];
        int j = i;
        while (j > 0 && a[j - 1] > value) {
            a[j] = a[j - 1];
            j--;
        }
        a[j] = value;
    }
}
```

资料采用相邻交换，这里改为先保存 value、向右移动较大的元素；主线相同，但一次移动不等于一次交换。只移动严格大于 value 的元素，因此保留相等键的顺序，排序稳定。

最好情况已排序，每轮只做常数工作，Θ(N)。最坏逆序，移动次数为 $N(N-1)/2$，Θ(N²)。额外空间 Θ(1)。

**Inversion**: 逆序对；i<j 但 a[i]>a[j]。对这个实现，时间可更精确描述为 Θ(N+I)，其中 I 是逆序对数量。资料“只有常数个元素未在有序位置”是一种可达到线性时间的近乎有序情况，不能把所有口语中的“差不多有序”直接判成线性。

## 3. Bubble Sort

**Bubble Sort**: 比较相邻两个元素，若前者更大就交换。一轮从左到右之后，未排序区最大值被推到末尾。

对 `[29,10,14,37,13]` 的第一轮：

```text
29 与 10 交换 → [10,29,14,37,13]
29 与 14 交换 → [10,14,29,37,13]
29 与 37 不换 → [10,14,29,37,13]
37 与 13 交换 → [10,14,29,13,37]
```

此时只是最后的 37 已确定，前面并未全部排好。

```java
static void bubbleSort(int[] a) {
    for (int end = a.length - 1; end > 0; end--) {
        boolean swapped = false;
        for (int j = 0; j < end; j++) {
            if (a[j] > a[j + 1]) {
                int saved = a[j];
                a[j] = a[j + 1];
                a[j + 1] = saved;
                swapped = true;
            }
        }
        if (!swapped) {
            return;
        }
    }
}
```

该实现增加了提前退出：完整一轮没有交换，就已经有序，最好 Θ(N)。最坏仍 Θ(N²)，额外空间 Θ(1)，严格大于才交换，因此稳定。

资料 §9.4 的基础版没有 swapped 检查，比较次数总是 $N(N-1)/2$，最好也为 Θ(N²)。做课件题时，必须以题目实际代码为准。

## 4. 自测

??? question "1. 选择排序处理完 i=0，前两个元素一定有序吗？"

    不一定。只确定位置 0 放着全局最小值，后面的顺序尚未解决。

??? question "2. 插入排序为什么 j>0 写在 && 左边？"

    Java 的 && 从左到右短路。j==0 时不再访问 a[j−1]，避免负索引。

??? question "3. 选择排序与冒泡排序，哪一个每轮确定末尾最大值？"

    本页从左向右扫描的冒泡排序。选择排序每轮确定开头最小值。改变遍历方向的变体可能相反。
