# 堆排序（Heapsort）

根据 `9.pdf` §9.7（PDF 第 39–46 页）整理。以下是重新编写的数组最大堆与迭代下沉实现。

## 1. 最大堆不是完整排序

**Max-Heap**: 最大堆；一棵完全二叉树，每个父节点的值都不小于其子节点。因此根节点是当前最大值，但左右子树之间不要求有序。

数组 `[9,7,8,2,3,4]` 是最大堆，却不是升序数组。

对从 0 开始的数组索引 i：

| 关系 | 索引 |
|---|---|
| 左孩子 | 2i+1 |
| 右孩子 | 2i+2 |
| 父节点，i>0 | floor((i−1)/2) |
| 最后一个非叶节点，N≥2 | floor(N/2)−1 |

没有子节点的叶子天然满足堆性质。这里的“堆”是数据结构，不是 Java 对象存储区域中的 heap memory。

## 2. Percolate Down

**Percolate Down**: 下沉；如果父节点小于某个孩子，把它和更大的孩子交换，再从那个孩子的位置继续。

必须选更大的孩子，否则另一个更大的孩子可能仍大于新的父节点。

建堆从最后一个非叶节点开始，向索引 0 处理。轮到某个父节点时，它的子树已经满足堆性质，才能只修复从该父节点向下的一条路径。

## 3. 从堆得到升序数组

1. 把整个数组建成最大堆。
2. 根是最大值，把根和当前堆末尾交换，最大值进入最终位置。
3. 缩小有效堆范围，排除刚放好的末尾元素。
4. 对新根下沉，恢复最大堆。
5. 重复，直到只剩一个元素。

以 `[3,1,4,2]` 为例：

| 阶段 | 有效堆 | 已排好的后缀 |
|---|---|---|
| 建堆完成 | `[4,2,3,1]` | 空 |
| 取出 4 并修复 | `[3,2,1]` | `[4]` |
| 取出 3 并修复 | `[2,1]` | `[3,4]` |
| 取出 2 | `[1]` | `[2,3,4]` |

## 4. Java 实现

```java
static void heapSort(int[] a) {
    for (int root = a.length / 2 - 1; root >= 0; root--) {
        siftDown(a, root, a.length);
    }
    for (int end = a.length - 1; end > 0; end--) {
        int saved = a[0];
        a[0] = a[end];
        a[end] = saved;
        siftDown(a, 0, end);
    }
}

static void siftDown(int[] a, int root, int size) {
    while (size >= 2 && root <= (size - 2) / 2) {
        int child = 2 * root + 1;
        if (child + 1 < size && a[child + 1] > a[child]) {
            child++;
        }
        if (a[root] >= a[child]) {
            return;
        }
        int saved = a[root];
        a[root] = a[child];
        a[child] = saved;
        root = child;
    }
}
```

a 非 null。size 是有效堆的元素数，区间为 `[0,size)`。例如把最大值放到索引 end 后，传 size=end，刚放好的元素不会再参与下沉。

下沉条件只让有左孩子的节点继续，`child + 1 < size` 再判断右孩子是否存在。

## 5. 时间与空间

一次下沉最多走树高 Θ(log N)。但建堆不是简单地把每个节点都算成 log N：多数节点在靠近叶子的位置，只能下沉很短距离。各高度的工作量累计使自底向上建堆为 Θ(N)。

反复取最大值阶段最坏 Θ(N log N)，整体最坏 Θ(N log N)。这个下沉实现遇到父节点已经不小于孩子时立即停止；全相等输入的建堆和每次取出都只需常数检查，总时间 Θ(N)。

本页使用迭代下沉，无递归，额外空间 Θ(1)。远距离交换可能改变相等键的原相对顺序，因此通常不稳定。

## 自测

??? question "1. 8 个元素，最后一个非叶节点的索引是什么？"

    floor(8/2)−1=3。建堆依次对 3、2、1、0 下沉。

??? question "2. 10 个元素，主方法总共调用几次 siftDown？"

    建堆 5 次，取出阶段 9 次，合计 14 次；一次调用内部可以有多次交换。

??? question "3. 堆排序是否一定用递归？"

    不是。这里两个主循环与下沉都使用迭代，因此不需要递归调用栈。
