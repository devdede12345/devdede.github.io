<a id="act-u1-recap-ranking"></a>

**活动 1.5.1：读取排名（U1-LO2、U1-LO8）**

继续从[代码中相同的排名（U1-LO2、U1-LO8）](1-1.md#code-u1-word-count-vectors)开始进行 cosine similarity 排名，代码为


```python
scores = np.array([1.0, 0.5, 0.0])
doc_names = np.array(["D1", "D2", "D3"])
ranking = doc_names[np.argsort(scores)[::-1]]
ranking
```


1. `ranking`的价值是多少？

2. 什么是排名？

3. 这个排名是根据距离还是方向？


??? success "解答"

    该值为`["D1", "D2", "D3"]`。文档按照与查询的 cosine similarity 进行排名。这是基于方向的排名，因为 cosine similarity 比较 normalization 后的方向。


<a id="act-u1-recap-attention"></a>

**活动 1.5.2：读取 attention 计算（U1-LO4、U1-LO8）**

在[代码中相同的 attention 计算（U1-LO4，U1-LO8）](1-3.md#code-u1-token-attention)中，代码是


```python
s = K @ q
alpha = s / s.sum()
out = alpha @ V
```


1. `s`包含什么？

2. 为什么`alpha`的entries 的和等于$1$？

3. `out`代表什么？


??? success "解答"

     vector `s`包含 dot product 分数。 vector `alpha`包含权重，因为分数除以它们的总和。 vector `out`是`V`行中存储的 value vector 的加权平均值。


<a id="act-u1-recap-geometry"></a>

**活动 1.5.3：读取几何计算（U1-LO5、U1-LO8）**

在[将一个 matrix 应用于多个点（U1-LO5、U1-LO8）](1-4.md#code-u1-matrix-many-points)中，代码是


```python
X = np.array([
    [0, 1, 1, 0, 0],
    [0, 0, 1, 1, 0],
], dtype=float)

A = np.array([
    [1, 1],
    [0, 1],
], dtype=float)

Y = A @ X
Y
```


1. `X`有哪些 column？

2. `Y`有哪些 column？

3. 这是画廊的哪个改造？


??? success "解答"

    `X` 的 column 是单位正方形的顶点。 `Y`的 column 是它们在$A$下的像。这是水平剪切，因为 $A$ 将 $(x,y)$ 发送到 $(x+y,y)$。


<a id="act-u1-recap-composition"></a>

**活动 1.5.4：解读映射的复合顺序 (U1-LO6)**


```python
S = np.array([
    [2., 0.],
    [0., 1.],
])

R = np.array([
    [0., -1.],
    [1.,  0.],
])

R @ S, S @ R
```


1. 哪种乘积先适用`S`，然后适用`R`？

2. 两个乘积相等吗？

3. 几何上的差异意味着什么？


??? success "解答"

    乘积`R @ S`首先应用`S`，然后应用`R`，因为最右边的 matrix 首先起作用。两个乘积不相等： 
    
    $$
    RS=\begin{bmatrix}0& -1\\2&0\end{bmatrix},
                  \qquad
                  SR=\begin{bmatrix}0& -2\\1&0\end{bmatrix}.
    $$
    
     水平拉伸后旋转与旋转后拉伸不同。


<a id="act-u1-recap-affine"></a>

**活动 1.5.5：读取 affine 规则 (U1-LO7)**


```python
W = np.array([
    [1., 1.],
    [0., 2.],
])

b = np.array([3., -1.])

def f(x):
    return W @ x + b
```

`f` 是 linear 的吗？使用 zero vector 证明你的答案。

??? success "解答"

    不可以。 linear map 必须将 $\mathbf{0}$ 发送到 $\mathbf{0}$。但 $f(\mathbf{0})=W\mathbf{0}+\mathbf{b}=\mathbf{b}$ 和 $\mathbf{b}$ 不是 zero vector。该规则是 affine 的，但不是 linear 的。
