## Mathematical quick reference {#mathematical-quick-reference}

### Systems and row reduction {#systems-and-row-reduction}

**Matrix equation**: 对于 $A\in\mathbb R^{m\times n}$，求解 $A\mathbf x=\mathbf b$，就是针对给定的 $\mathbf b\in\mathbb R^m$ 寻找 $\mathbf x\in\mathbb R^n$。使用[ linear 方程对应的 matrix ](2-2.md#def-1-1-coefficient-matrices)中定义的 augmented matrix $[A\mid\mathbf b]$。

**Elementary row operations**: 交换两个 rows；将一行乘以非零 scalar；将一行的某个倍数加到另一行上。每次变换都作用于 augmented matrix 的全部 column，包括右端 column。由[定理 2.2.1](2-2.md#thm-equivalent-row-ops)，这些变换不改变解集。

**Echelon forms**: 在本书的 row echelon form （REF）约定中，零行位于底部；每个非零 row 的首个非零元素为 1，即 pivot；从上往下看，各 row pivot 的位置依次向右移动，且每个 pivot 下方都为零。 reduced row echelon form （RREF）还要求每个 pivot 都是其所在 column 唯一的非零元素。见[ row echelon form 与 reduced row echelon form ](2-2.md#def-1-2-row-echelon-form)与[Gaussian elimination 算法](2-2.md#alg-gaussian-elimination)。

**Classify and solve**: row reduction 后，若出现形如 $[0\ \cdots\ 0\mid d]$ 且 $d\neq0$ 的 row，则无解；否则方程组相容。分隔线左侧的 pivot column 对应pivot variable，其余变量 column 对应 free variable。可以从 REF back-substitution，或直接从 RREF 读出方程，将pivot variable表示为 free variable 的 function，见[解决](2-2.md#alg-1-2-gaussian-elimination-algorithm)。

**Number of parameters**: 相容方程组有 $n$ 个变量，分隔线左侧有 $r$ 个 pivot column 时，自由参数的数量为 $n-r$。若 $r=n$，则解唯一；若 $r\lt n$，则有无穷多解。见[定理 2.2.3](2-2.md#thm-1-2-number-parameters-linear)。

**Homogeneous systems and basic solutions**: homogeneous system 形如 $A\mathbf x=\mathbf0$，总有平凡解 $\mathbf x=\mathbf0$。依次让一个 free variable 为 $1$、其余 free variable 为 $0$，再求出pivot variable，就为每个 free variable 得到一个 basic solution。每个齐次解都是这些 basic solution 的唯一 linear combination。见[homogeneous system 的 basic solution ](2-2.md#def-1-3-homog-basic-solutions)。

**General solution**: 若 $\mathbf x_p$ 是 $A\mathbf x=\mathbf b$ 的一个解，则 

$$
\{\mathbf x:A\mathbf x=\mathbf b\}=\mathbf x_p+\operatorname{null}(A).
$$

因此，任何其他解与 $\mathbf x_p$ 的差都是 homogeneous system 的一个解。见[ linear system 的 general solution ](2-3.md#fact-u2-general-solution-null-space)。

### Lines, planes, and subspaces {#lines-planes-and-subspaces}

**Line**: 经过 $\mathbf p$、方向为 $\mathbf v\neq\mathbf0$ 的直线：

$$
\mathbf x=\mathbf p+t\mathbf v,\qquad t\in\mathbb R.
$$

在 $\mathbb R^3$ 中，如果方向 vector 的三个 component 均非零，可以写成对称式 

$$
\frac{x_1-p_1}{v_1}=\frac{x_2-p_2}{v_2}=\frac{x_3-p_3}{v_3}.
$$

如果某个方向 component 为零，就保留相应 coordinate 为常数的方程，不能除以零。见[直线的 parametric equation ](2-2.md#def-1-2-parametric-equation-for-line)。

**Plane in three dimensions**: 经过 $\mathbf p$、 normal vector 为 $\mathbf n\neq\mathbf0$ 的平面满足 $\mathbf n\cdot(\mathbf x-\mathbf p)=0$。若 $\mathbf n=(a,b,c)$，则对应 scalar 方程 $ax+by+cz=d$，其中 $d=\mathbf n\cdot\mathbf p$。等价地，取平面内两个 linearly independent 的方向，可写作 $\mathbf x=\mathbf p+s\mathbf u+t\mathbf v$，其中 $s,t\in\mathbb R$。见[平面 normal vector 方程](2-2.md#def-1-2-normal-vector-equation)。

**Plane intersections**: 将平面方程合并成方程组，再对 augmented matrix 做 row reduction。 normal vector 不平行的两个平面相交于一条直线； normal vector 平行时，两平面可能重合，也可能没有交点。见[平行平面](2-2.md#warn-u2-parallel-planes)。

**Subspace test**: $\mathbb R^n$ 的子集若包含 $\mathbf0$，且对加法和 scalar multiplication 封闭，就是 subspace。 homogeneous system 的解集是 subspace。见[ subspace ](2-3.md#def-5-1-subspaces)。

**Span**: $\operatorname{span}\{\mathbf v_1,\ldots,\mathbf v_k\}$ 是所列 vectors 的一切 linear combination 组成的集合。要检验 $\mathbf b$ 是否属于它，可以对 $[\mathbf v_1\ \cdots\ \mathbf v_k]\mathbf c=\mathbf b$ 的 augmented matrix 做 row reduction。 span 是 subspace，见[ vector 组的 span ](2-3.md#def-5-1-span)与[定理 2.3.2](2-3.md#sec-u2-spanning-sets-6)。

### Independence, bases, and coordinates {#independence-bases-and-coordinates}

**Linear independence**: vector 组 $\mathbf v_1,\ldots,\mathbf v_k$  linearly independent，当且仅当 

$$
c_1\mathbf v_1+\cdots+c_k\mathbf v_k=\mathbf0\quad\Longrightarrow\quad c_1=\cdots=c_k=0.
$$

把这些 vector 作为 column，求解相应 homogeneous system 即可检验；若存在nontrivial解，则 linearly dependent。见[ linear independence 的检验](2-4.md#sec-u2-linear-independence-7)。

**Basis and dimension**: basis 是 linearly independent 的 spanning set。有限维 subspace 的所有 basis 都包含相同数量的 vector，这个数量就是 dimension。空集是 $\{\mathbf0\}$ 的 basis，其 dimension 为 $0$。见[ vector space 的 basis ](2-4.md#sec-5-2-bases)与[不变性定理](2-4.md#thm-5-2-invariance-theorem)。

**Basis tests and construction**: 若 $\dim(U)=d$，那么 $U$ 中的 $d$ 个 vector 构成 basis，当且仅当它们 linearly independent，也当且仅当它们 span $U$。$U$ 中的 linearly independent 的 vector 集合可以扩充为 basis，$U$ 的 spanning set 可以删减为 basis。见[事实 2.4.1](2-4.md#fact-5-2-expanding-linearly-independent)与[ basis 与 dimension ](2-4.md#sec-u2-basis-and-dimension)。

**Comparing dimensions**: 若 subspace 满足 $U\subseteq W$，则 $\dim(U)\leq\dim(W)$。如果 dimension 相等，则 $U=W$。

**Coordinates**: 设 $B=(\mathbf b_1,\ldots,\mathbf b_k)$ 是 $U$ 的 ordered basis，且 $\mathbf v\in U$，则 

$$
\mathbf v=c_1\mathbf b_1+\cdots+c_k\mathbf b_k,\qquad C_B(\mathbf v)=\begin{bmatrix}c_1\\\vdots\\c_k\end{bmatrix}.
$$

求出唯一的 coefficient vector 即可得到 coordinate。 coordinate 取决于 basis vector 的顺序，并且有 $C_B(\mathbf b_i)=\mathbf e_i$。见[相对于 basis coordinate vector ](2-4.md#subsec-bases-coordinate-systems-7)。

### Fundamental spaces, rank, and nullity {#fundamental-spaces-rank-and-nullity}

**Image, column, row, and null spaces**: 设 $A\in\mathbb R^{m\times n}$。它的所有可达输出组成 image space，也就是各 column 的 span：

$$
\operatorname{im}(A)=\operatorname{col}(A)=\{A\mathbf x:\mathbf x\in\mathbb R^n\}\subseteq\mathbb R^m.
$$

row space $\operatorname{row}(A)$ 是各 row 的 span，属于 $\mathbb R^n$ 的 subspace。被映射忽略的输入方向组成 

$$
\operatorname{null}(A)=\{\mathbf x\in\mathbb R^n:A\mathbf x=\mathbf0\}.
$$

见[ null space 与 image space ](2-3.md#def-5-1-null-and-image-space-of-matrix)与[ column space 与 row space ](2-4.md#def-5-3-column-and-row-space)。

**Basis calculations**: 利用 REF 或 RREF 找出 pivot column，再从原 matrix $A$ 中选取对应的 column，作为 column space 的一组 basis。行变换不改变 row space，所以 REF 或 RREF 的非零行构成 row space 的一组 basis。$A\mathbf x=\mathbf0$ 的 basic solution 构成 null space 的一组 basis。见[ rank 定理](2-4.md#thm-5-3-rank-theorem)与[ rank — nullity 定理](2-4.md#thm-5-3-rank-nullity)。

**A basis for a span**: 将给定生成 vector 放入 matrix 的各 row，化为 REF，取非零行即可得到一组 basis，见[求 span 的一组 basis (U2-LO4)](2-4.md#act-5-3-basis-for-V)。如果要求 basis 必须取自原来的生成 vector，则应将 vector 放在 column 中，并选取原 matrix 的 pivot column。

**Rank and nullity**: rank 是 column space 与 row space 共同的 dimension， nullity 是 null space 的 dimension：

$$
\operatorname{rank}(A)=\dim\operatorname{col}(A)=\dim\operatorname{row}(A),
$$

 

$$
\operatorname{nullity}(A)=\dim\operatorname{null}(A).
$$

见[ matrix 的 rank ](2-4.md#def-u2-rank-dimension)与[定义 2.4.8](2-4.md#sec-rank-of-a-matrix-14)。由[通过 row reduction 计算 rank ](2-4.md#def-1-2-rank)，REF 或 RREF 中的 pivot 数量就是 rank； nullity 则等于 $A\mathbf x=\mathbf0$ 的 free variable 数量。

**Rank–nullity**: 对于 $A\in\mathbb R^{m\times n}$，由[ rank — nullity 定理](2-4.md#thm-5-3-rank-nullity)可得 

$$
\operatorname{rank}(A)+\operatorname{nullity}(A)=n.
$$

column 数 $n$ 就是输入 dimension：保留的 dimension 加上被忽略的输入 dimension，恰好覆盖全部输入 dimension。

**Existence and uniqueness**: $A\mathbf x=\mathbf b$ 相容，当且仅当 $\mathbf b\in\operatorname{col}(A)$。在相容的前提下，解唯一，当且仅当 $\operatorname{null}(A)=\{\mathbf0\}$。

**Different inputs, same output**: 

$$
A\mathbf x=A\mathbf y\quad\Longleftrightarrow\quad\mathbf x-\mathbf y\in\operatorname{null}(A).
$$

若nonzero vector $\mathbf z\neq\mathbf0$ 属于 null space，那么在 $\mathbf x+t\mathbf z$ 中改变 $t\in\mathbb R$，就会得到不同的输入，而输出始终与 $\mathbf x$ 相同。见[来自 null space 方向的相同输出（U2-LO3、U2-LO6）](2-4.md#u2-act-same-output-null-space-direction)。

**Redundant features**: 数据 matrix $X$ 的 column linearly dependent，就存在nonzero vector $\mathbf z$ 满足 $X\mathbf z=\mathbf0$。因此 

$$
X(\mathbf c+t\mathbf z)=X\mathbf c,\qquad t\in\mathbb R.
$$

不同 coefficient vector 可以给出完全相同的预测，所以预测不能唯一确定各个 coefficient。 rank 计算保留下来的 linearly independent 特征方向数， nullity 计算数据 matrix 无法察觉的 linearly independent coefficient 变化方向数。见[房屋数据中的冗余特征](2-4.md#ex-u2-redundant-house-features)与[代码中的冗余考试分数特征（U2-LO3、U2-LO6）](2-6.md#act-u2-recap-redundant-footage-code)。

### Inverses and determinants {#inverses-and-determinants}

**Inverse**: 若存在 matrix $A^{-1}$ 使 

$$
AA^{-1}=A^{-1}A=I_n.
$$

则称 square matrix $A$  invertible，也称非奇异。 inverse matrix 唯一，并将映射反向：$A\mathbf x=\mathbf b$ 的解为 $\mathbf x=A^{-1}\mathbf b$。见[ matrix 的 invertibility ](2-5.md#sec-matrix-inverses-2-2)与[定理 2.5.2](2-5.md#sec-matrix-inverses-2-14)。

**Invertibility criteria**: 对于 $n\times n$  square matrix $A$，下面各条都等价于 invertibility：


- 各 columns 彼此 linearly independent；等价地，各 column span $\mathbb R^n$；也等价于它们构成 $\mathbb R^n$ 的一组 basis。

- 各 row linearly independent；等价地，各 row span $\mathbb R^n$；也等价于它们构成 $\mathbb R^n$ 的一组 basis。

- $\operatorname{null}(A)=\{\mathbf0\}$，即 $A\mathbf x=\mathbf0$ 只有平凡解。

- $\operatorname{rref}(A)=I_n$；等价地，$\operatorname{rank}(A)=n$。

- 对于每个 $\mathbf b\in\mathbb R^n$，方程组 $A\mathbf x=\mathbf b$ 都有唯一解。

- $\det(A)\neq0$.


请参阅[ invertibility 准则](2-5.md#fact-5-2-invertibility-criteria)和[定理 2.5.13](2-5.md#sec-determinants-and-matrix-inverses-38)。

**Two-by-two determinant and inverse**: 

$$
\det\begin{bmatrix}a& b\\c& d\end{bmatrix}=ad-bc.
$$

当 $ad-bc\neq0$ 时，

$$
\begin{bmatrix}a& b\\c& d\end{bmatrix}^{-1}=\frac1{ad-bc}\begin{bmatrix}d&-b\\-c& a\end{bmatrix}.
$$

见[定理 2.5.3](2-5.md#thm-2-5-determinant-of-two-by-two)。

**Minors and cofactors**: minor $\operatorname{minor}(A)_{ij}$ 是删去第 $i$  row 与第 $j$  column 后，剩余子 matrix 的 determinant。 cofactor 满足 

$$
\operatorname{cof}(A)_{ij}=(-1)^{i+j}\operatorname{minor}(A)_{ij}.
$$

见[ minor a](2-5.md#sec-determinants-and-matrix-inverses-6)、[的 cofactor ](2-5.md#sec-determinants-and-matrix-inverses-8)与[一般 square matrix 的 determinant ](2-5.md#sec-determinants-and-matrix-inverses-18)。

**Cofactor expansion**: 固定一行 $i$，有 

$$
\det(A)=\sum_{j=1}^n a_{ij}\operatorname{cof}(A)_{ij}.
$$

固定一个 column $j$，有 

$$
\det(A)=\sum_{i=1}^n a_{ij}\operatorname{cof}(A)_{ij}.
$$

无论选择哪行或哪 column，都得到相同的 determinant。选含零元素较多的行或 column，可以减少计算量，见[事实 2.5.5](2-5.md#sec-determinants-and-matrix-inverses-19)。

**Determinant rules**: 交换两行会使 determinant 变号；将一行乘以 $c$，会使 determinant 乘以 $c$；将另一行的倍数加到某行上，不改变 determinant。见[ row operation 如何影响 determinant ](2-5.md#sec-determinants-and-matrix-inverses-33)。若有零 row、零 column，或两个 rows、两个 columns 相等，则 determinant 为零。 triangular matrix 的 determinant 等于对角线元素的乘积。对于 $n\times n$  matrix，有 

$$
\det(AB)=\det(A)\det(B),\qquad \det(A^T)=\det(A).
$$

整个 matrix scalar multiplication 会缩放全部 $n$ 行：

$$
\det(cA)=c^n\det(A).
$$

见[事实 2.5.6](2-5.md#sec-determinants-and-matrix-inverses-30)。

**Inverse identities**: 若 $A,B$ 是同阶 invertible matrix，则 $(AB)^{-1}=B^{-1}A^{-1}$ 且 $\det(A^{-1})=1/\det(A)$。见[定理 2.5.1](2-5.md#sec-matrix-inverses-2-8)与[定理 2.5.13](2-5.md#sec-determinants-and-matrix-inverses-38)。

**Optional: computing an inverse by row reduction**: 将 $[A\mid I_n]$  row reduction 为 $[I_n\mid A^{-1}]$。如果完整的 row reduction 不能使左侧成为 $I_n$，则 $A^{-1}$ 不存在。这是[选读：计算 inverse matrix ](2-5.md#subsec-u2-linear-independence-invertibility)中的选读内容，见[计算算法](2-5.md#sec-matrix-inverses-4-6)。

## Common mistakes {#common-mistakes}


- 将增强 column 计为变量 column，缺少不相容的 row，或省略自由参数。只有垂直线左侧的 column 代表变量。

- 使用 REF 或 RREF column 作为 column space basis。使用原 matrix 的相应 column；减少的非零行适合 row space basis。

- 混淆 row space 和 column space。对于 $m\times n$  matrix，它们分别位于 $\mathbb R^n$ 和 $\mathbb R^m$，即使它们的 dimension 相同。

- 假设 spanning set 是不检查 linear independence 的 basis，或者假设三个或更多成对的非平 row vector 必须是 linearly independent 的。请参阅[两两不平行的 vector 仍可能 linearly dependent ](2-4.md#warn-u2-nonparallel-not-independent)。

- 将平移的直线或平面称为 subspace，而不检查原点和闭合。特别是，$A\mathbf x=\mathbf b$与$\mathbf b\neq\mathbf0$的解集不包含原点。

- 将特征之间的每个关系视为 linear 冗余。例如，面积是宽度和高度的乘积，而不是它们的 linear combination；参见[注意](2-4.md#aside-redundant-features-4)。

- 结论是相同的预测意味着相同的 coefficient。非零 null space 方向允许 coefficient 变化而不改变预测。

- 对 rectangular matrix 应用 square matrix inverse matrix 或 determinant 测试，或者混淆缩放一行与缩放整个 matrix 的 determinant 效果。

- 将从零开始的 pivot 索引读取为从一开始的数学 column 号。描述 column 号时加一，但使用Python原来的从零开始的索引；参见[在 SymPy 中选取原 matrix 的 pivot column (U2-LO3, U2-LO4)](2-4.md#act-u2-sympy-pivot-column-list)。

- 将 `A.nullspace()` 视为单个 vector。它返回 basis column matrix 的列表；在相乘之前从非空列表中选择一个 vector。空列表意味着 null space 为 $\{\mathbf0\}$；参见[使用 SymPy null space vector （U2-LO3、U2-LO4、U2-LO6）](2-4.md#act-u2-sympy-nullspace-list-product)。
