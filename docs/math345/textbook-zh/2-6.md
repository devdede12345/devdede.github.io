**活动 2.6.1：不记录高度的传感器 (U2-LO3, U2-LO6)**

传感器仅记录水平位置。它保留前两个 coordinate 并降低高度。


```python
import numpy as np

P = np.array([
    [1., 0., 0.],
    [0., 1., 0.],
])

x = np.array([2., 1., 5.])
z = np.array([0., 0., 1.])

P @ x, P @ (x + 6*z), P @ z
```

输出：


```text
(array([2., 1.]), array([2., 1.]), array([0., 0.]))
```


1. $P$ 对输入 vector 有什么作用？

2. 为什么$P\mathbf{x}$和$P(\mathbf{x}+6\mathbf{z})$一致？

3. $P\mathbf{z}=\mathbf{0}$关于方向$\mathbf{z}$说明了什么？

4. 为什么不能从输出中唯一地恢复原始输入？


??? success "解答"

     matrix $P$ 保留前两个 coordinate 并忘记第三个。

     vector 



    $$
    \mathbf{x}
                =
                \begin{bmatrix}
                2\\
                1\\
                5
                \end{bmatrix}
                \qquad\text{and}\qquad
                \mathbf{x}+6\mathbf{z}
                =
                \begin{bmatrix}
                2\\
                1\\
                11
                \end{bmatrix}
    $$



    具有不同的高度，但前两个 coordinate 相同。因此它们的输出是一致的。

    自从



    $$
    P\mathbf{z}=\mathbf{0},
    $$



    方向



    $$
    \mathbf{z}
                =
                \begin{bmatrix}
                0\\
                0\\
                1
                \end{bmatrix}
    $$



    是一个被遗忘的方向。相差 $\mathbf{z}$ 倍数的输入具有相同的输出。


<a id="act-u2-recap-null-space-basis"></a>

**活动 2.6.2：读取代码中的 null space basis （U2-LO3、U2-LO6）**

以下代码要求 SymPy 提供 null space 的 basis。回想一下 [使用 SymPy null space vector （U2-LO3、U2-LO4、U2-LO6）](2-4.md#act-u2-sympy-nullspace-list-product) 如何从返回的列表中选择一个 vector 并将其乘以 matrix。


```python
import sympy as sp

A = sp.Matrix([
    [1, 2, 3],
    [2, 4, 6],
    [0, 1, 1],
])

A.nullspace()
```

输出：


```text
[Matrix([
[-1],
[-1],
[ 1]])]
```


1. `nullspace()`返回什么样的对象？

2. 显示的 vector 是输入方向还是输出方向？

3. 从代码输出中验证$\mathbf{z}
                  =
                  \begin{bmatrix}
                  -1\\
                  -1\\
                  1
                  \end{bmatrix}$位于$\operatorname{null}(A)$中。

4. 如果$A\mathbf{x}=\mathbf{y}$，那么$A(\mathbf{x}+t\mathbf{z})$是多少？


??? success "解答"

    该命令返回 $\operatorname{null}(A)$ 的 basis vector 列表。

     vector 



    $$
    \mathbf{z}
                =
                \begin{bmatrix}
                -1\\
                -1\\
                1
                \end{bmatrix}
    $$



    是输入方向。它满足



    $$
    A\mathbf{z}
                =
                \mathbf{0}.
    $$



    如果$A\mathbf{x}=\mathbf{y}$，那么



    $$
    A(\mathbf{x}+t\mathbf{z})
                =
                A\mathbf{x}+tA\mathbf{z}
                =
                \mathbf{y}+t\mathbf{0}
                =
                \mathbf{y}.
    $$



    因此，$\mathbf{x}+t\mathbf{z}$形式的每个输入都会给出相同的输出。


<a id="act-u2-recap-augmented-rref-output"></a>

**活动 2.6.3：读取增强的 rref 输出（U2-LO1、U2-LO2、U2-LO3）**

回想一下[读取代码中的 row reduction （U2-LO1、U2-LO2）](2-2.md#act-u2-reading-row-reduction-code)如何读取 row reduction 输出。有关解压结果并使用从零开始的索引选择条目，请参阅[在 SymPy 中选取原 matrix 的 pivot column (U2-LO3, U2-LO4)](2-4.md#act-u2-sympy-pivot-column-list)。

代码 row reduction 了试图解决的 augmented matrix 



$$
A\mathbf{x}=\mathbf{b},
            \qquad
            A=
            \begin{bmatrix}
            1& 0\\
            0& 1\\
            1& 1
            \end{bmatrix},
            \qquad
            \mathbf{b}
            =
            \begin{bmatrix}
            1\\
            2\\
            4
            \end{bmatrix}.
$$




```python
import sympy as sp

# Augmented matrix [A | b]
M = sp.Matrix([
    [1, 0, 1],
    [0, 1, 2],
    [1, 1, 4],
])

M.rref()
```

输出：


```text
(Matrix([
[1, 0, 0],
[0, 1, 0],
[0, 0, 1]]), (0, 1, 2))
```

将显示的 matrix 读取为



$$
\left[
            \begin{array}{cc|c}
            1&0&0\\
            0&1&0\\
            0&0&1
            \end{array}
            \right].
$$




1. 最后一行代表什么？

2. $\mathbf{b}$ 作为$A$ 的输出是否可达？

3. 垂直线右侧的 pivot 是什么意思？


??? success "解答"

    最后一行是



    $$
    [0\ 0\mid 1],
    $$



    它代表方程



    $$
    0=1.
    $$



    该方程是不可能的，因此系统是不相容的。因此，$\mathbf{b}$ 无法作为 $A$ 的输出到达。

     pivot 位于垂直线右侧意味着系统无解。


<a id="act-u2-recap-redundant-footage-code"></a>

**活动 2.6.4：代码中的冗余考试分数特征（U2-LO3、U2-LO6）**

使用 [ linear independence、 basis 与 dimension ](2-4.md#sec-u2-independence-bases-dimension) 中的考试部分和总计示例。行代表学生。这四 column 记录了第 1 部分、第 2 部分、第 3 部分的分数以及考试总分，全部以分数为单位。


```python
import numpy as np

X = np.array([
    [8., 6., 4., 18.],
    [5., 9., 7., 21.],
    [7., 4., 9., 20.],
    [6., 8., 5., 19.],
])

z = np.array([1., 1., 1., -1.])
c = np.array([2., 3., 1., 0.])
c_alt = np.array([1., 2., 0., 1.])

rank = np.linalg.matrix_rank(X)

X @ z, rank, X @ c, X @ c_alt
```

输出：


```text
(array([0., 0., 0., 0.]),
 3,
 array([38., 44., 35., 41.]),
 array([38., 44., 35., 41.]))
```


1. $X\mathbf{z}=\mathbf{0}$ 的四个特征 column 说明了什么？

2. $\operatorname{rank}(X)=3$对这四个特征有何说明？

3. 为什么$X\mathbf{c}$和$X\mathbf{c}_{\mathrm{alt}}$一致？

4. 这对解释单个 coefficient 有何警告？


??? success "解答"

    等式



    $$
    X
                \begin{bmatrix}
                1\\
                1\\
                1\\
                -1
                \end{bmatrix}
                =
                \mathbf{0}
    $$



    意味着



    $$
    \text{total}
                =
                \text{part 1}+\text{part 2}+\text{part 3}
    $$



    对于每个学生。总分 column 是三个部分分数列的 linear combination。

    这四 column 仅包含三个 linearly independent 的特征方向，因此$\operatorname{rank}(X)=3$。总计没有添加 linearly independent 的特征方向。

     coefficient vector 因 null space 方向而异：



    $$
    \mathbf{c}-\mathbf{c}_{\mathrm{alt}}
                =
                \begin{bmatrix}
                2\\
                3\\
                1\\
                0
                \end{bmatrix}
                -
                \begin{bmatrix}
                1\\
                2\\
                0\\
                1
                \end{bmatrix}
                =
                \begin{bmatrix}
                1\\
                1\\
                1\\
                -1
                \end{bmatrix}
                =
                \mathbf{z}.
    $$



    自$X\mathbf{z}=\mathbf{0}$以来，



    $$
    X\mathbf{c}
                =
                X(\mathbf{c}_{\mathrm{alt}}+\mathbf{z})
                =
                X\mathbf{c}_{\mathrm{alt}}+X\mathbf{z}
                =
                X\mathbf{c}_{\mathrm{alt}}.
    $$



    第一个 coefficient vector 将权重 $2,3,1$ 放在三个部分上，并将权重为零。第二个将 $1,2,0$ 赋予零件，将 $1$ 赋予总数。它们给出相同的预测，因此这些 coefficient 本身并不能确定唯一最重要的考试特征。


<a id="act-u2-recap-column-space-basis-debug"></a>

**活动 2.6.5：从代码调试 column space basis （U2-LO3、U2-LO4）**

学生计算 rref 和 pivot column。回想一下 [在 SymPy 中选取原 matrix 的 pivot column (U2-LO3, U2-LO4)](2-4.md#act-u2-sympy-pivot-column-list) 中的 column 切片和列表理解。


```python
import sympy as sp

A = sp.Matrix([
    [1, 2, 3],
    [2, 4, 6],
    [0, 1, 1],
])

R, pivots = A.rref()
R, pivots
```

输出：


```text
(Matrix([
[1, 0, 1],
[0, 1, 1],
[0, 0, 0]]), (0, 1))
```

学生说：“$R$的第1个 column 和第2个 column 是$\operatorname{col}(A)$的 basis。”


1. pivot 索引 `(0, 1)` 在数学 column 编号中意味着什么？

2. 使用$R$的 column 作为$\operatorname{col}(A)$的 basis 有什么问题吗？

3. 应该使用哪些 column？

4. 写出$\operatorname{col}(A)$的 basis。


??? success "解答"

     pivot 索引 `(0, 1)` 表示数学 column 1 和 2。

    错误在于row operations没有保留$A$的原 matrix 的 column。 row reduction 确定 pivot position，但 $\operatorname{col}(A)$ 的 basis 必须使用原 matrix $A$ 的 column。

    因此我们使用 $A$ 的第 1 column 和第 2 column：



    $$
    \left\{
                \begin{bmatrix}
                1\\
                2\\
                0
                \end{bmatrix},
                \begin{bmatrix}
                2\\
                4\\
                1
                \end{bmatrix}
                \right\}.
    $$



    这些 vector 构成了 $\operatorname{col}(A)$ 的 basis。


<a id="act-u2-recap-determinant-inverse-diagnostics"></a>

**活动 2.6.6：代码中的 determinant 和逆诊断（U2-LO3、U2-LO5、U2-LO7）**

以下代码检查两个 square matrix 的 determinant 和 rank。


```python
import numpy as np

A = np.array([
    [1., 1.],
    [0., 1.],
])

B = np.array([
    [1., 0.],
    [0., 0.],
])

detA = float(np.linalg.det(A))
detB = float(np.linalg.det(B))

rankA = np.linalg.matrix_rank(A)
rankB = np.linalg.matrix_rank(B)

detA, rankA, detB, rankB
```

输出：


```text
(1.0, 2, 0.0, 1)
```


1. 哪个 matrix 是 invertible 的？

2. 哪个 matrix 忘记了非零输入方向？

3. determinant 和 rank 各自表示什么？

4. $B\mathbf{x}=\mathbf{b}$ 是否应该为每个 $\mathbf{b}\in\mathbb{R}^2$ 提供唯一的解？


??? success "解答"

     matrix $A$ 是 invertible 的，因为



    $$
    \det(A)=1\ne 0
    $$



    和



    $$
    \operatorname{rank}(A)=2.
    $$



     matrix $B$ 是奇异的，因为



    $$
    \det(B)=0
    $$



    和



    $$
    \operatorname{rank}(B)=1\lt 2.
    $$



     matrix $B$ 忘记了非零方向



    $$
    \begin{bmatrix}
                0\\
                1
                \end{bmatrix},
    $$



    自从



    $$
    B
                \begin{bmatrix}
                0\\
                1
                \end{bmatrix}
                =
                \begin{bmatrix}
                0\\
                0
                \end{bmatrix}.
    $$



    不应期望系统$B\mathbf{x}=\mathbf{b}$对每个$\mathbf{b}$都有唯一的解。该映射不可反转。
