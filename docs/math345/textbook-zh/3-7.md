```python
x, y = sp.symbols("x y")

J = F.jacobian([x, y])
J
```

输出：



$$
J=
          \begin{bmatrix}
          y& x\\
          2x& 1
          \end{bmatrix}.
$$




1. `F`的组件功能有哪些？

2. `J`是什么形状？

3. `J`的第一个 column 测量什么？


??? success "解答"

     component function 为$F_1(x,y)=xy$和$F_2(x,y)=x^2+y$。 Jacobian matrix 是$\begin{bmatrix}y&x\\2x&1\end{bmatrix}$，所以它是$2\times 2$。它的第一个 column 测量两个输出 component 相对于第一个输入变量 $x$ 的变化情况。


<a id="act-u3-recap-sympy-derivative-order"></a>

**活动 3.7.2：评估前求导 (U3-LO3)**


```python
import sympy as sp
x, y = sp.symbols("x y")
f = 3*x**2*y + 2*x - 3*y
point = {x: 1, y: 2}
a = sp.diff(f, x).subs(point)
b = sp.diff(f.subs(point), x)
grad_f = sp.Matrix([sp.diff(f, x), sp.diff(f, y)])
H = sp.hessian(f, (x, y))
a, b, grad_f.shape, H.shape
```

输出：`(14, 0, (2, 1), (2, 2))`。


1. `a` 和 `b` 哪个是 $f_x(1,2)$？解释为什么另一个为零。

2. `sp.diff(f, y, x)` 计算什么？它在 $(1,2)$ 的值是多少？

3. 这里哪个 derivative matrix 等于`grad_f.jacobian([x, y])`？它的形状与 scalar-valued function $f$ 的 Jacobian matrix 有何不同？


??? success "解答"

    `a` 是 $f_x(1,2)=14$。在`b`中，替换首先将$f$变成常数$2$，其 derivative 为零。命令`sp.diff(f, y, x)`计算$f_{yx}=(f_y)_x$：它先对$y$进行微分，然后对$x$进行微分，给出$6x$，因此在该点处给出$6$。 gradient 的 Jacobian matrix 是$2\times2$ Hessian matrix； scalar-valued function 的 Jacobian matrix 是$1\times2$行$(\nabla f)^T$。


<a id="act-u3-recap-prediction-loss-pipeline"></a>

**活动 3.7.3：读取预测误差更新（U3-LO1、U3-LO4、U3-LO6、U3-LO9）**

此 NumPy 计算使用与 [一步改进模型的预测（U3-LO8、U3-LO9）](3-6.md#act-u3-prediction-loss-descent) 相同的误差平方和。 vector 存储为一维数组。


```python
import numpy as np
X = np.array([[1., 0.], [0., 1.], [1., 1.]])
y = np.array([1., 2., 2.])
w = np.array([1., 1.])
r = X @ w - y
g = 2 * X.T @ r
w_next = w - 0.1*g
r_next = X @ w_next - y
np.round([r @ r, g @ (w_next - w), r_next @ r_next], 2)
```

输出：`[1.00, -0.40, 0.68]`。


1. 识别预测、 residual、 scalar 损失和 gradient。给出`r`和`g`的形状。

2. 为什么 chain rule 给出`2 * X.T @ r`而不是`2 * X @ r`？

3. 哪个显示值可以预测损失变化？预测的新损失和实际变化是多少？

4. 下降是否证明下一个 gradient 为零，每个 learning rate 都有效，或者数据已经完全拟合？


??? success "解答"

    预测为`X @ w`， residual 为`r`，形状为`(3,)`，损失为`r @ r`， gradient 为`g`，形状为`(2,)`。 residual 映射有 Jacobian matrix $X$；平方长度 function 的 Jacobian matrix $2\mathbf r^T$。它们的乘积是$2\mathbf r^TX$，其 transpose 是 gradient $2X^T\mathbf r$。第二个输出$-0.40$预测变化，因此预测损失为$0.60$。实际变化是$0.68-1=-0.32$。新的 gradient 为$(0.4,-1.2)$； learning rate $1$将损失增加到$5$；正平方误差意味着拟合不精确。

<a id="act-u3-recap-nonlinear-block"></a>

**活动 3.7.7：读取小型 Sigmoid 模块（U3-LO6、U3-LO7）**


```python
def sigmoid(t):
    return 1 / (1 + np.exp(-t))

W1 = np.array([
    [1.0, 0.0],
    [0.0, 1.0],
    [1.0, 1.0],
])

W2 = np.array([
    [1.0, 0.0, -0.5],
    [0.0, 1.0,  0.5],
])

b1 = np.zeros(3)
b2 = np.zeros(2)

x = np.array([0.0, 0.0])

s = W1 @ x + b1
u = sigmoid(s)
D = np.diag(u * (1 - u))
y = W2 @ u + b2
J_at_x = W2 @ D @ W1

s, u, y, J_at_x
```

输出：



$$
\begin{aligned}
\mathbf s&=\begin{bmatrix}0.0\\0.0\\0.0\end{bmatrix}, \\
\mathbf u&=\begin{bmatrix}0.5\\0.5\\0.5\end{bmatrix}, \\
\mathbf y&=\begin{bmatrix}0.25\\0.75\end{bmatrix}, \\
J_{\mathbf x}&=\begin{bmatrix}0.125&-0.125\\0.125&0.375\end{bmatrix}.
\end{aligned}
$$




1. 哪些线包含 affine map ？

2. 哪一行包含 coordinate nonlinear 步骤？

3. `s`、`u`、`y`代表什么？

4. 哪条线构成对角 derivative matrix？

5. 哪一行计算 `x` 处块的 Jacobian matrix？

6. `J_at_x`是什么形状？


??? success "解答"

    线 `s = W1 @ x + b1` 和 `y = W2 @ u + b2` 是 affine map。线 `u = sigmoid(s)` 是 coordinate nonlinear 步骤。

     vector `s`是预激活 vector。 vector `u`是应用sigmoid后的隐藏 vector。 vector `y`是输出 vector。

    自 $\sigma'(t)=\sigma(t)(1-\sigma(t))$ 以来，线 `D = np.diag(u * (1 - u))` 在此输入处形成 sigmoid derivative 的 diagonal matrix。

    第`J_at_x = W2 @ D @ W1`行通过 Jacobian matrix 的 chain rule 计算`x`处块的 Jacobian matrix。 `J_at_x`的形状是$2\times 2$：输入有两个 coordinate，输出有两个 coordinate。

**活动 3.7.8：读取 gradient descent 循环（U3-LO8、U3-LO9）**

假设 `grad_f(x)` 计算 $\nabla f(\mathbf{x})$。考虑代码：


```python
x = x0
for k in range(num_steps):
    x = x - alpha * grad_f(x)
```


1. 代表什么数学更新规则？

2. learning rate 是多少？

3. `grad_f(x)` 必须具有什么形状？

4. 如果减号是加号，会发生什么变化？

5. 这段代码是否证明已经找到了最小值？


??? success "解答"

    该循环代表更新

    $$
    \mathbf{x}_{k+1}=\mathbf{x}_k-\alpha\nabla f(\mathbf{x}_k).
    $$

     learning rate 为`alpha`。 vector `grad_f(x)` 必须与 `x` 具有相同的形状，因为更新会从一个 vector 中减去另一个 vector。如果将减号替换为加号，则更新将朝着最急剧增加的方向而不是最急剧减少的方向移动。该循环并不证明已找到最小值。只描述重复更新；收敛取决于 function、起点、 learning rate 和停止规则。

<a id="act-u5-reading-next-token-loss-optimization"></a>

**活动 3.7.10：解读下一个 token 的预测损失（U3-LO8、U3-LO9）**


<a id="subsec-u3-training-objectives-final-layer-updates"></a>


<a id="ai-u5-next-token-optimization"></a>

语言模型先为可能的下一个 token 生成 scores，再将 scores 转换为 probabilities。训练 loss 衡量模型给真实下一个 token 分配了多大概率：概率越低，惩罚越大。对于序列 $t_1,\ldots,t_L$，一个简化的训练目标为：

$$
\mathcal L(\boldsymbol{\theta})
            =
            -\sum_{i=1}^{L-1}
            \log p_{\boldsymbol{\theta}}
            \bigl(t_{i+1}\mid t_1,\ldots,t_i\bigr).
$$

参数 vector $\boldsymbol{\theta}$可以收集许多 matrix 和偏差 vector。

gradient descent 步骤的形式为 

$$
\boldsymbol{\theta}_{k+1}
            =
            \boldsymbol{\theta}_k
            -\alpha\nabla\mathcal L(\boldsymbol{\theta}_k).
$$




1. 参数是什么？

2. 最小化的数量是多少？

3. 哪个符号表示 learning rate ？

4. gradient 指向什么？

5. 尽管我们没有研究完整的模型训练，为什么这是一个 optimization problem ？

6. 为什么这不会自动成为 least squares 问题？


??? success "解答"

    参数收集在$\boldsymbol{\theta}$中。目标$\mathcal L(\boldsymbol{\theta})$是损失。 learning rate 为$\alpha$。 gradient $\nabla\mathcal L(\boldsymbol{\theta}_k)$给出了局部增长最快的方向，因此使用负 gradient 进行下降。这是一个 optimization problem，因为训练意味着调整参数以减少损失。

    显示的目标中没有任何内容具有 

    $$
    \|A\mathbf c-\mathbf y\|^2
    $$

     形式，具有固定 matrix $A$ 和单个训练 coefficient vector $\mathbf c$。它是通过 gradient descent 优化的一般 differentiable 损失。


<a id="act-u5-final-layer-gradient"></a>

**活动 3.7.11：最终 linear 层的 gradient （U3-LO6、U3-LO9、U2-LO3）**

假设固定的隐藏表示为

$$
\mathbf h\in\mathbb R^d,
$$

最终 linear 层计算

$$
\boldsymbol{\ell}=W\mathbf h,
            \qquad
            W\in\mathbb R^{m\times d}.
$$

令

$$
\mathbf g=\nabla_{\boldsymbol{\ell}}\mathcal L
            \in\mathbb R^m
$$

为相对于输出分数的损失 gradient。


1. 对于

$$
\ell_i=\sum_{j=1}^d W_{ij}h_j,
$$

使用 chain rule 证明

$$
\frac{\partial\mathcal L}{\partial W_{ij}}
                =
                g_i h_j.
$$



2. 结论是

$$
\nabla_W\mathcal L=\mathbf g\mathbf h^T.
$$



3. 这个 matrix 的形状是什么？

4. 为什么这个 matrix 的 rank 至多为 1？

5. 解读更新

$$
W_{\mathrm{new}}
                =
                W-\alpha\mathbf g\mathbf h^T.
$$




??? success "解答"

    从

    $$
    \ell_k=\sum_{j=1}^d W_{kj}h_j,
    $$

    开始，我们有

    $$
    \frac{\partial \ell_k}{\partial W_{ij}}
                =
                \begin{cases}
                h_j,&k=i,\\
                0,&k\neq i.
                \end{cases}
    $$

    

     chain rule 给出 

    $$
    \frac{\partial\mathcal L}{\partial W_{ij}}
                =
                \sum_{k=1}^m
                \frac{\partial\mathcal L}{\partial\ell_k}
                \frac{\partial\ell_k}{\partial W_{ij}}
                =
                g_i h_j.
    $$

     因此 

    $$
    \nabla_W\mathcal L=\mathbf g\mathbf h^T.
    $$

    

    如果$\mathbf g\in\mathbb R^m$和$\mathbf h\in\mathbb R^d$，则该 outer product 的形状为$m\times d$。每个 column 都是 $\mathbf g$ 的 scalar 倍数，因此它的 rank 最多为 1。对于这个训练示例，更新在负 gradient 方向上改变了$W$。

**活动 3.7.12：代码中相同的最后层更新（U3-LO6、U3-LO9、U2-LO3）**


```python
G = np.outer(g, h)
W_new = W - alpha * G
```


1. 哪项早期活动给出了 `G` 表示的公式？

2. `G`是什么形状？

3. 为什么这里使用`np.outer(g, h)`？

4. 第二行代表什么数学更新？

5. 为什么这与 rank 有关？


??? success "解答"

    [最终 linear 层的 gradient ](3-7.md#act-u5-final-layer-gradient)、

    $$
    G=\mathbf g\mathbf h^T=\nabla_W\mathcal L.
    $$

    

    如果 $\mathbf g$ 的长度为 $m$ 并且 $\mathbf h$ 的长度为 $d$，则 `G` 的形状为 $m\times d$。即使两个 vector 存储为一维 NumPy 数组，命令 `np.outer(g, h)` 也会形成 outer product。第二行代表

    $$
    W_{\mathrm{new}}
                =
                W-\alpha\nabla_W\mathcal L.
    $$

    

    对于单个训练样本，gradient matrix 是两个 vectors 的 outer product，因此 rank 至多为 1。这只是在描述此次更新，并不意味着 $W$ 或 $W_{\mathrm{new}}$ 的 rank 也至多为 1。
