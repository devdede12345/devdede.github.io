**活动 4.5.1：解读 least squares 中的对象（U4-LO4，U4-LO7）**

以下代码重复“[重访第二章的目标 vector ](4-3.md#act-u4-unit2-target-revisited)”。


```python
A = np.array([
    [1.0, 0.0],
    [0.0, 1.0],
    [1.0, 1.0],
])

b = np.array([1.0, 2.0, 4.0])

xhat = np.linalg.lstsq(A, b, rcond=None)[0]
bhat = A @ xhat
r = b - bhat

xhat.shape, bhat.shape, r.shape, A.T @ r
```


1. `xhat` 的形状是什么？

2. `bhat` 的形状是什么？

3. `r` 的形状是什么？

4. `xhat` 保存什么数学对象？

5. `bhat` 保存什么数学对象？

6. 哪个变量保存最近的可达输出？

7. `A.T @ r` 检查什么？

8. `A.T @ r` 接近零，是否意味着 `r` 接近 zero vector？


??? success "解答"

     matrix $A$ 有两个 columns、三 row。因此 `xhat` 的形状为 `(2,)`，而 `bhat`、`r` 的形状均为 `(3,)`。

     vector `xhat` 保存 least squares coefficient vector 


    $$
    \widehat{\mathbf{x}}
                =
                \begin{bmatrix}
                4/3\\
                7/3
                \end{bmatrix}.
    $$


     vector `bhat` 保存 fitted vector 


    $$
    \widehat{\mathbf{b}}
                =
                A\widehat{\mathbf{x}}
                =
                \begin{bmatrix}
                4/3\\
                7/3\\
                11/3
                \end{bmatrix}.
    $$


     vector `r` 保存 residual 


    $$
    \mathbf{r}
                =
                \mathbf{b}-\widehat{\mathbf{b}}
                =
                \begin{bmatrix}
                -1/3\\
                -1/3\\
                1/3
                \end{bmatrix}.
    $$


    最近的可达输出是 `bhat`，而不是 `xhat`。

    乘积


    ```python
    A.T @ r
    ```

    计算 residual 与 $A$ 各 column 的 dot product，检查


    $$
    \mathbf{r}
                \perp
                \operatorname{col}(A).
    $$


    这并不表示 residual 为零。本例中，


    $$
    \|\mathbf{r}\|^2
                =
                \frac13,
    $$


    所以 residual 非零。

**活动 4.5.2：roundoff error 与错误的 residual 检查（U4-LO4，U4-LO7）**

对“[解读 least squares 中的对象](4-5.md#act-u4-recap-residual-orthogonality)”中的同一问题，假设 NumPy 给出


```python
A.T @ r
```

其输出为


```python
array([2.2e-16, -1.1e-16])
```

以及


```python
np.linalg.norm(r)
```

其输出为


```python
0.5773502691896257
```


1. 第一个输出检查什么几何条件？

2. 为什么 component 极小，却不恰好为零？

3. 第一个输出是否表示 residual vector 为零？

4. 第二个输出说明什么？

5. 为什么下面的表达式


    ```python
    np.allclose(A.T @ r, np.zeros(A.shape[1]))
    ```

    比 `A.T @ r == 0` 更适合做数值检查？

6. 某位学生改写为


    ```python
    A @ r
    ```

    来检查 residual orthogonality。此表达式有什么问题？


??? success "解答"

    第一个输出检查 residual 是否与 $A$ 的每个 column orthogonal。精确运算下，


    $$
    A^T\mathbf{r}
                =
                \mathbf{0}.
    $$


    浮点运算可能产生极小 roundoff error，而不是精确零。

    第一个输出不表示 $\mathbf{r}=\mathbf{0}$。第二个输出说明


    $$
    \|\mathbf{r}\|
                \approx
                0.57735
                =
                \frac{1}{\sqrt{3}},
    $$


    所以 residual 非零。

     function `np.allclose` 检查 component 是否在容差范围内接近零。逐个 component 检查严格相等，通常对浮点输出过于苛刻。

    `A @ r` 不是正确检查。这里 $A$ 的形状为 $3\times2$，而 $\mathbf{r}$ 长度为 $3$，所以乘积甚至没有定义。更重要的是， residual orthogonality 要求与 $A$ 各 column 作 dot product，这些 dot product 收集在


    $$
    A^T\mathbf{r}.
    $$

**活动 4.5.3：解读回归的 design matrix （U4-LO4，U4-LO7）**

以下代码重复“[为三个数据点拟合直线](4-3.md#act-u4-fit-line-three-points)”。


```python
t = np.array([0.0, 1.0, 2.0])
y = np.array([1.0, 2.0, 2.0])

X = np.column_stack([np.ones_like(t), t])

c = np.linalg.lstsq(X, y, rcond=None)[0]
yhat = X @ c
r = y - yhat
```


1. $X$ 的两个 columns 分别代表什么？

2. 为什么 `c` 有两个 component ？

3. 为什么 `yhat` 有三个 component ？

4. 哪个变量是 fitted vector？

5. 哪个变量是 coefficient vector？

6. 哪个 vector 属于 $\operatorname{col}(X)$？

7. “[同一直线拟合的两种视角](4-3.md#fig-u4-regression-two-views)”中哪个面板展示 $\mathbb{R}^3$ 中的 projection？

8. 在 $t$–$y$ 数据图中， residual 线段是竖直的，还是垂直于拟合直线的？

9. 下面的表达式计算什么量？


    ```python
    np.linalg.norm(r)**2
    ```

    ?


??? success "解答"

    $X$ 的第一个 column 是常数特征，第二个 column 包含输入值 $t$。

     vector `c` 有两个 component，因为模型有 intercept 和 slope 两个 coefficient； vector `yhat` 有三个 component，因为模型在三个输入处各作一次预测。

     coefficient vector 为


    $$
    \widehat{\mathbf{c}}
                =
                \begin{bmatrix}
                7/6\\
                1/2
                \end{bmatrix}.
    $$


     fitted vector 为


    $$
    \widehat{\mathbf{y}}
                =
                X\widehat{\mathbf{c}}
                =
                \begin{bmatrix}
                7/6\\
                5/3\\
                13/6
                \end{bmatrix}.
    $$


    因此 `c` 是 coefficient vector，`yhat` 是 fitted vector。`yhat` 属于 $\operatorname{col}(X)$。

    “[同一直线拟合的两种视角](4-3.md#fig-u4-regression-two-views)”的下图 (b) 展示 $\mathbb{R}^3$ 中的 projection。在 $t$–$y$ 数据图中， residual 线段是竖直的，一般不垂直于拟合直线。

    最后，


    ```python
    np.linalg.norm(r)**2
    ```

    计算 residual 平方和，其值为


    $$
    \frac16
    $$


    允许存在 roundoff error。


<a id="act-u4-review-qr-code"></a>

**活动 4.5.4：解读 QR least squares 代码（U4-LO6，U4-LO7）**

以下代码将 [QR least squares 算法](4-4.md#alg-u4-qr-least-squares) 应用于 [同一直线拟合](4-3.md#act-u4-fit-line-three-points)。


```python
Q, R = np.linalg.qr(X, mode="reduced")

c_qr = np.linalg.solve(R, Q.T @ y)

np.allclose(Q.T @ Q, np.eye(Q.shape[1]))
np.allclose(Q @ R, X)
c_qr
```


1. `Q` 与 `R` 的形状应是什么？

2. 第一行 `np.allclose` 检查什么？

3. 第二个 row `np.allclose` 检查什么？

4. 下面的表达式求解什么数学方程组？


    ```python
    np.linalg.solve(R, Q.T @ y)
    ```

    ?

5. 为什么含 $R$ 的方程组比原 least squares 问题更容易求解？

6. `c_qr` 应接近什么？

7. 得到 `c_qr` 是否意味着


    $$
    X\mathbf{c}=\mathbf{y}
    $$


    有精确解？

8. 为什么 NumPy 返回的 $Q$、$R$ 可能与手算 Gram–Schmidt 的符号不同？


??? success "解答"

     design matrix $X$ 的形状为 $3\times2$，因此约化 QR 给出


    ```python
    Q.shape == (3, 2)
    R.shape == (2, 2)
    ```

    第一个检查验证


    $$
    Q^TQ=I_2,
    $$


    所以 $Q$ 的 columns 构成 orthonormal set。第二个检查验证


    $$
    QR=X.
    $$


    调用


    ```python
    np.linalg.solve(R, Q.T @ y)
    ```

    求解


    $$
    R\widehat{\mathbf{c}}
                =
                Q^T\mathbf{y}.
    $$


     matrix $R$ 是上三角 square matrix，因此这是标准 linear system，而不是矩形 least squares 问题。

    结果应接近


    ```python
    array([1.16666667, 0.5])
    ```

    它表示


    $$
    \widehat{\mathbf{c}}
                =
                \begin{bmatrix}
                7/6\\
                1/2
                \end{bmatrix}.
    $$


    这不意味着 $X\mathbf{c}=\mathbf{y}$ 有精确解， fitted vector 的 residual 非零。

     QR factorization 允许同时改变 $Q$ 的某 column 和 $R$ 的对应 row 的符号。因此数值软件可以返回与手算不同的符号，同时仍满足


    $$
    Q^TQ=I
                \qquad\text{and}\qquad
                QR=X.
    $$
