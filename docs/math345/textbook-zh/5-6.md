## 回顾活动

**活动 5.6.1：读取 Hessian  eigenvalues （U5-LO4、U5-LO5）**

假设  critical point  有  Hessian matrix 


```python
H = np.array([[4.0, 0.0],
              [0.0, -1.0]])

evals, evecs = np.linalg.eig(H)
evals
```

输出：


```python
array([ 4., -1.])
```


1. 研究什么 matrix ？

2. eigenvalues  的符号与  quadratic form  $\mathbf{h}^T H\mathbf{h}$ 有何关系？

3. 如果$H$是 Hessian 在 critical point 处， second derivative test 得出什么结论？

4. 为什么必须强调“在  critical point  处”这个前提？

??? success "解答"

    正在研究的 matrix 是 Hessian matrix 。它的 eigenvalues 符号相反，所以 quadratic form $\mathbf{h}^T H\mathbf{h}$既可以取正值，也可以取负值。如果$H$是 critical point 处的 Hessian ，则 second derivative test 将 critical point 分类为 saddle point 。短语“at a  critical point ”很重要，因为 Hessian 测试对一阶项消失后的局部行为进行分类。

**活动 5.6.2：读取  least-squares   residual  检查（U5-LO6、U4-LO4）**

考虑代码：


```python
xhat = np.linalg.lstsq(A, b, rcond=None)[0]
r = b - A @ xhat
A.T @ r
```


1. `xhat`是什么？

2. `r`是什么？

3. `A.T @ r` 检查什么条件？

4. `A.T @ r`“接近于零”是否意味着`r`“接近于零”？

5. 哪个早期单位使用了相同的条件？

??? success "解答"

    vector  `xhat` 是 least-squares   coefficient vector 。  vector  `r` 是 residual  

    $$
    \mathbf{r}=\mathbf{b}-A\hat{\mathbf{x}}.
    $$

     表达式`A.T @ r` 检查 residual  是否是 orthogonal  到$A$ 的 columns 。即使`r`不接近于零，它也可以接近于零。第 4 单元使用相同的  residual - orthogonality  条件来导出  normal equations 。单元 5 通过将 $\|A\mathbf{x}-\mathbf{b}\|^2$ 的  gradient  设置为零来获得相同的方程。

**活动 5.6.3：读取光谱工具（U5-LO1、U5-LO3、U5-LO4）**

考虑代码：


```python
A = np.array([[2.0, 1.0],
              [1.0, 2.0]])

evals, Q = np.linalg.eigh(A)
D = Q.T @ A @ Q
x = np.array([1.0, -1.0])
q = x @ (A @ x)
```

一种可能的输出是


$$
\begin{aligned}
\texttt{evals}&=\begin{bmatrix}1\\3\end{bmatrix}, \\
Q&=\frac{1}{\sqrt2}\begin{bmatrix}-1&1\\1&1\end{bmatrix}, \\
D=Q^TAQ&=\begin{bmatrix}1&0\\0&3\end{bmatrix}, \\
q=\mathbf x^TA\mathbf x&=2.
\end{aligned}
$$


1. `evals`的条目和`Q`的 columns 代表什么？

2. 为什么`Q.T @ A @ Q`给出 diagonal matrix ？

3. `x @ (A @ x)`计算什么？

4. 使用 eigenvalues 对 quadratic form $q_A(\mathbf x)=\mathbf x^TA\mathbf x$进行分类。

??? success "解答"

    `evals`的条目是 eigenvalues 、$1$和$3$。 `Q`对应的 columns 是 orthonormal  eigenvectors 。 NumPy 可以返回  eigenvector  的任一符号，因此显示的  columns  的符号可能会改变，而不会改变数学。

    因为$A$是 symmetric ，所以它的 orthonormal  eigenvectors 形成 orthogonal matrix $Q$的 columns ，$Q^TAQ$是 eigenvalues 的 diagonal matrix 。表达式 `x @ (A @ x)` 计算  quadratic form  $q_A(\mathbf x)=\mathbf x^TA\mathbf x$，对于显示的  vector  等于 $2$。  eigenvalues  都是正数，所以 $q_A$ 是  positive definite 。
