**练习 2.7.1：代码中的 projection 和遗忘高度**

传感器仅记录水平位置。它保留前两个 coordinate 并降低高度。


```python
import numpy as np

P = np.array([
    [1., 0., 0.],
    [0., 1., 0.],
])

x = np.array([2., 1., 5.])
z = np.array([0., 0., 1.])

rank = np.linalg.matrix_rank(P)
nullity = P.shape[1] - rank

P @ x, P @ (x + 6*z), P @ z, rank, nullity
```

输出：


```text
(array([2., 1.]), array([2., 1.]), array([0., 0.]), 2, 1)
```


1. $P$ 对输入 vector 有什么作用？

2. 为什么$P\mathbf{x}$和$P(\mathbf{x}+6\mathbf{z})$一致？

3. $P\mathbf{z}=\mathbf{0}$关于方向$\mathbf{z}$说明了什么？

4. 解释 rank 和 nullity。

5. 为什么不能从输出中唯一地恢复原始输入？


学习目标。 U2-LO3、U2-LO6。

**练习 2.7.2：增强 rref 的可达输出**

让



$$
A=
            \begin{bmatrix}
            1&0\\
            0&1\\
            1&1
            \end{bmatrix},
            \qquad
            \mathbf{b}_1=
            \begin{bmatrix}
            1\\
            2\\
            3
            \end{bmatrix},
            \qquad
            \mathbf{b}_2=
            \begin{bmatrix}
            1\\
            2\\
            4
            \end{bmatrix}.
$$



以下代码对 augmented matrix 进行 row reduction 



$$
A\mathbf{x}=\mathbf{b}_1
            \qquad\text{and}\qquad
            A\mathbf{x}=\mathbf{b}_2.
$$




```python
import sympy as sp

M1 = sp.Matrix([
    [1, 0, 1],
    [0, 1, 2],
    [1, 1, 3],
])

M2 = sp.Matrix([
    [1, 0, 1],
    [0, 1, 2],
    [1, 1, 4],
])

M1.rref(), M2.rref()
```

输出：


```text
((Matrix([
[1, 0, 1],
[0, 1, 2],
[0, 0, 0]]), (0, 1)),
 (Matrix([
[1, 0, 0],
[0, 1, 0],
[0, 0, 1]]), (0, 1, 2)))
```

将两个 rref matrix 读取为



$$
\left[
            \begin{array}{cc|c}
            1&0&1\\
            0&1&2\\
            0&0&0
            \end{array}
            \right],
            \qquad
            \left[
            \begin{array}{cc|c}
            1&0&0\\
            0&1&0\\
            0&0&1
            \end{array}
            \right].
$$




1. 哪个目标 vector 是可达的？

2. 哪个目标 vector 不可达？

3. 哪一行显示不相容？

4. 垂直线右侧的 pivot 是什么意思？

5. 对于可达到的目标，给出一个输入$\mathbf{x}$。


学习目标。 U2-LO1、U2-LO2、U2-LO3。

**练习 2.7.10：读取逆运算输出**

以下代码 row reduction $[A\mid I_3]$。


```python
import sympy as sp

A = sp.Matrix([
    [1, 1, 4],
    [2, 3, 2],
    [0, 0, 1],
])

M = A.row_join(sp.eye(3))
M.rref()
```

输出：


```text
(Matrix([
[1, 0, 0,  3, -1, -10],
[0, 1, 0, -2,  1,   6],
[0, 0, 1,  0,  0,   1]]), (0, 1, 2))
```

将 rref matrix 读取为



$$
\left[
            \begin{array}{ccc|ccc}
            1&0&0&3&-1&-10\\
            0&1&0&-2&1&6\\
            0&0&1&0&0&1
            \end{array}
            \right].
$$




1. 垂直线的左侧显示什么？

2. $A$ invertible 吗？

3. 读出$A^{-1}$。

4. 为什么 row reduction $[A\mid I_3]$ 会给出相反的结果？
