<a id="sec-abstract-vector-spaces"></a>

前几章主要研究 $\mathbb R^n$ 中的  vectors ，但相同的代数规则也适用于  matrices  和 polynomial。本节给出抽象定义，让后续课程可以用统一的语言研究不同对象： vectors  可以是  columns 、 matrices 、polynomial，或其他满足相同规则的对象。


<a id="def-5-5-abstract-vector"></a>

**定义 7.1.1**

一个 real  vector space  由非空集合 $V$ 及其上的两种运算组成。集合中的对象称为  vectors ；它们可以相加，也可以与实数相乘，这里的实数称为  scalar 。这些运算需要满足下面的十条 axioms。若 $\mathbf{v}$ 和 $\mathbf{w}$ 是 $V$ 中的两个  vectors ，它们的和记为 $\mathbf{v} + \mathbf{w}$；$\mathbf{v}$ 与实数 $a$ 的  scalar  乘积记为 $a \mathbf{v}$。 vector space  的 axioms 如下：
<a id="li-5-5-A1"></a>

**(A1) 添加项下的关闭**: 如果$\mathbf{u}$和$\mathbf{v}$是$V$中的任意元素，则$\mathbf{u} + \mathbf{v}$在$V$中。


<a id="li-5-5-A2"></a>

**(A2) 加法交换律**: 对于任何$\mathbf{u},\mathbf{v} \in V$，$\mathbf{u} + \mathbf{v} = \mathbf{v} + \mathbf{u}$。


<a id="li-5-5-A3"></a>

**(A3) 加法的结合性**: 对于任何$\mathbf{u},\mathbf{v},\mathbf{w} \in V$，$\mathbf{u} + (\mathbf{v} + \mathbf{w}) = (\mathbf{u} + \mathbf{v}) + \mathbf{w}$。


<a id="li-5-5-A4"></a>

**(A4)  Zero Vector  的存在性**: $V$中存在 zero vector $\mathbf{0}$，因此$\mathbf{u} + \mathbf{0} = \mathbf{0} + \mathbf{u} = \mathbf{u}$对于任何$\mathbf{u} \in V$。


<a id="li-5-5-A5"></a>

**(A5) 加法逆元的存在性**: 对于每个$\mathbf{v} \in V$，$V$中存在$-\mathbf{v}$，使得

$$
\mathbf{v} + (-\mathbf{v}) = -\mathbf{v} + \mathbf{v} = \mathbf{0}
$$

vector  $- \mathbf{v}$ 是$\mathbf{v}$ 的负数或 additive inverse 。


<a id="li-5-5-S1"></a>

**(S1)  Scalar Multiplication 以下关闭**: 如果$\mathbf{v}$是$V$的任意元素且$a$是任意实数，则$a \mathbf{v}$在$V$中。


<a id="li-5-5-S2"></a>

**(S2)分配律1**: 对于任何$\mathbf{u},\mathbf{v} \in V$和任何$a \in \mathbb{R}$，$a (\mathbf{u} + \mathbf{v}) = a\mathbf{u} + a \mathbf{v}$。


<a id="li-5-5-S3"></a>

**(S3)分配律2**: 对于任何$\mathbf{v} \in V$和任何$a,b \in \mathbb{R}$，$(a + b) \mathbf{v} = a \mathbf{v} + b \mathbf{v}$。


<a id="li-5-5-S4"></a>

**(S4)  Scalar Multiplication  的结合性**: 对于任何$\mathbf{v} \in V$和$a,b \in \mathbb{R}$，$a(b\mathbf{v}) = (ab) \mathbf{v}$。


<a id="li-5-5-S5"></a>

**(S5)**: $1 \mathbf{v} = \mathbf{v}$ 对于任何 $\mathbf{v} \in V$。


其中，运算 $\mathbf{v} + \mathbf{w}$ 称为  vector addition ，运算 $a\mathbf{v}$ 称为  scalar multiplication 。

**说明**

为了清楚所使用的运算，我们经常分别使用符号$\oplus$和$\odot$来表示新定义的加法和 scalar multiplication 运算。

**说明**

在本课程中，我们经常使用短语“ vector space ”，省略“实数”并假设我们的 scalars 是实数。但是，可以使用与实数不同的  scalars  系统来定义复数  vector  空间、有理  vector  空间等。

**说明**

从现在开始，“ vector ”将表示 vector space 的元素，不一定是 column vector 或线段。

本单元主要的例子是 

$$
\mathbb R^n,\qquad M_{m,n},\qquad \mathcal P_{\le d}.
$$

 这里$M_{m,n}$是$m\times n$ matrices 的集合，

$$
\mathcal P_{\le d}
    =
    \{a_0+a_1x+\cdots+a_dx^d:a_0,\ldots,a_d\in\mathbb R\}.
$$

在$\mathbb R^n$中，加法和 scalar multiplication 是逐项的。在$M_{m,n}$中，它们是按条目排列的。在$\mathcal P_{\le d}$中，它们是多项式加法和 scalar multiplication 。所有多项式的集合$\mathcal P$也是 vector space ，但它是无限维的，不会是我们的主要例子。

**活动 7.1.1： Matrix  加法、 scaling  和  zero vector  (U7-LO1)**

考虑所有 $2\times2$  matrices  中的  vector space  $\mathbf{M}_{22}$。

**问题**

证明$\mathbf{M}_{22}$在加法和 scalar multiplication 下是闭集。这个 vector space 中的 zero vector 是什么？

??? success "解答"

    对于$\mathbf{M}_{22}$中的两个 matrices 

    $$
    \begin{bmatrix} a & b \\ c & d \end{bmatrix} \quad\text{and}\quad \begin{bmatrix} e & f \\ g & h \end{bmatrix}
    $$

    它们的和是

    $$
    \begin{bmatrix} a + e & b + f \\ c + g & d + h \end{bmatrix}
    $$

    它是$\mathbf{M}_{22}$的元素。  scalar  $k$ 与  matrix  

    $$
    \begin{bmatrix} a & b \\ c & d \end{bmatrix}
    $$

     的乘积是 

    $$
    k \begin{bmatrix} a & b \\ c & d \end{bmatrix} = \begin{bmatrix} ka & kb \\ kc & kd \end{bmatrix}
    $$

    它是 $\mathbf{M}_{22}$ 的元素。

**问题**

$\mathbf{M}_{22}$中的 zero vector 是什么？

??? success "解答"

    $\mathbf{M}_{22}$中的 zero vector 是 zero matrix 

    $$
    \mathbf{0} = \begin{bmatrix} 0 & 0 \\ 0 & 0 \end{bmatrix}
    $$

    因为$X + \mathbf{0} = \mathbf{0} + X$对于任何$X \in \mathbf{M}_{22}$。

**活动 7.1.2：检查多项式的  vector  空间公理 (U7-LO1)**

让我们来看看$\mathcal P_{\le2}$是 vector space 的证明。

??? success "解答"

    我们一一分析每个公理：

    让我们首先验证 Axiom (A1)。我们必须验证次数最多为 2 的两个多项式之和的次数最多为 2。令$u(x) = a_0 + a_1 x + a_2 x^2$和$v(x) = b_0 + b_1 x + b_2 x^2$为$\mathcal P_{\le2}$中的两个任意多项式。那么

    $$
    (u + v)(x) = (a_0 + b_0) + (a_1 + b_1) x + (a_2 + b_2) x^2
    $$

    的度数最多为$2$，所以位于$\mathcal P_{\le2}$。因此公理 (A1) 成立。

    接下来，我们验证公理（A2）。我们必须验证对于任意两个多项式$u,v \in \mathcal P_{\le2}$，$u + v = v + u$。但利用实数的交换律，对于任何实数$x$，如果$u(x) = a_0 + a_1 x + a_2 x^2$和$v(x) = b_0 + b_1 x + b_2 x^2$，则

    $$
    \begin{aligned}
    (u + v)(x) & = (a_0 + a_1 x + a_2 x^2) + (b_0 + b_1 x + b_2 x^2) \\
    & = (b_0 + b_1 x + b_2 x^2) + (a_0 + a_1 x + a_2 x^2) \\
    & = (v + u)(x)
    \end{aligned}
    $$

    因此公理 (A2) 成立。

    接下来，我们验证公理（A3）。我们必须验证对于任意两个多项式$u,v,w \in \mathcal P_{\le2}$，$u + (v + w) = (u + v) + w$。但是，如上所述，通过使用实数的结合律，即，如果$u(x) = a_0 + a_1 x + a_2 x^2$、$v(x) = b_0 + b_1 x + b_2 x^2$和$w(x) = c_0 + c_1 x + c_2x^2$，则对于任何$x \in \mathbb{R}$、

    $$
    \begin{aligned}
    (u + (v + w))(x) & = u(x) + (v(x) + w(x)) \\
    & = (a_0 + a_1 x + a_2 x^2) \\
    & \quad + ( (b_0 + b_1 x + b_2 x^2) + (c_0 + c_1 x + c_2x^2) ) \\
    & = (a_0 + b_0 + c_0) + (a_1 + b_1 + c_1) x \\
    & \quad + (a_2 + b_2 + c_2) x^2 \\
    & = ( (a_0 + a_1 x + a_2 x^2) + (b_0 + b_1 x + b_2 x^2) ) \\
    & \quad + (c_0 + c_1 x + c_2x^2) \\
    & = ((u + v) + w)(x)
    \end{aligned}
    $$

    因此公理 (A3) 成立。

    接下来，我们验证Axiom（A4）。我们必须检查如果$\mathbf{0}$是零多项式，那么$\mathbf{0} + v = v$对于任何$v \in \mathcal P_{\le2}$。现在，如果 $v = a_0 + a_1 x + a_2 x^2$，则对于任何 $x \in \mathbb{R}$，

    $$
    \begin{aligned}
    \mathbf{0}(x) + v(x) & = (0 + 0x + 0x^2) + (a_0 + a_1 x + a_2 x^2) \\
    & = (0 + a_0) + (0 + a_1) x+ (0 + a_2)x^2 \\
    & = a_0 + a_1 x + a_2 x^2 \\
    & = v(x)
    \end{aligned}
    $$

     因此公理 (A4) 成立。

    接下来，我们验证Axiom（A5）。对于$u(x) = a_0 + a_1 x + a_2 x^2$给出的每个多项式$u \in \mathcal P_{\le2}$，如果我们定义$(-u)(x) = (-a_0) + (-a_1) x + (-a_2) x^2$，则定义$u + (-u) = 0$。确实

    $$
    \begin{aligned}
    (u + (-u))(x) & = (a_0 + a_1 x + a_2 x^2) + ( (-a_0) + (-a_1) x + (-a_2) x^2) \\
    & = ((a_0 - a_0) + (a_1 - a_1) x + (a_2 - a_2) x^2) \\
    & = 0
    \end{aligned}
    $$

    因此$u + (-u) = 0$，验证公理（A5）。

    接下来，我们验证 Axiom (S1)。我们必须验证$\mathbf{v} \in \mathcal P_{\le2}$和$r \in \mathbb{R}$、$r \mathbf{v} \in \mathcal P_{\le2}$。如果$u(x) = a_0 + a_1 x + a_2x^2$，还有 scalar $r$、

    $$
    \begin{aligned}
    (ru)(x) & = r(a_0 + a_1x + a_2x^2) \\
    & = (ra_0) + (ra_1) x + (ra_2) x^2
    \end{aligned}
    $$

    多项式$ru$仍然最多有$2$次数，因此$ru \in \mathcal P_{\le2}$。因此公理 (S1) 成立。

    接下来，我们验证 Axiom (S2)。我们必须验证对于任何$u,v \in \mathcal P_{\le2}$和$r \in \mathbb{R}$，然后是$r(u + v) = ru + rv$。如果$u(x) = a_0 + a_1x + a_2x^2$和$v(x) = b_0 + b_1x + b_2x^2$，则

    $$
    \begin{aligned}
    (r(u + v))(x) & = r( (a_0 + a_1x + a_2x^2) + (b_0 + b_1x + b_2x^2) ) \\
    & = (ra_0 + rb_0) + (ra_1 + rb_1) x + (ra_2 + rb_2) x^2 \\
    & = (ru + rv)(x)
    \end{aligned}
    $$

    因此公理 (S2) 成立。

    接下来，我们验证 Axiom (S3)。我们必须验证对于任何$u \in \mathcal P_{\le2}$和$r,s \in \mathbb{R}$、$(r + s) u = ru + su$。如果$u(x) = a_0 + a_1 x + a_2x^2$，则

    $$
    \begin{aligned}
    ((r + s) u)(x) & = (r + s)( a_0 + a_1 x + a_2x^2 ) \\
    & = ( (ra_0 + sa_0) + (ra_1 + sa_1) x + (ra_2 + sa_2) x^2 ) \\
    & = (ru + su)(x)
    \end{aligned}
    $$

    因此公理 (S3) 成立。

    接下来，我们验证 Axiom (S4)。我们必须验证对于任何$r,s \in \mathbb R$和$u \in \mathcal P_{\le2}$、$r(s u) = (rs) u$。如果$u(x) = a_0 + a_1 x + a_2 x^2$，则

    $$
    \begin{aligned}
    (r(s u))(x) & = r(s(a_0 + a_1 x + a_2 x^2)) \\
    & = (rs)(a_0 + a_1 x + a_2 x^2) \\
    & = ((rs) u)(x)
    \end{aligned}
    $$

    因此公理 (S4) 成立。

    最后，我们验证 Axiom (S5)。我们必须验证对于任何$u \in \mathcal P_{\le2}$、$1 u = u$。如果$u(x) = a_0 + a_1x + a_2x^2$，则

    $$
    (1 u)(x) = 1 (a_0 + a_1 x + a_2x^2) = u(x)
    $$

    因此公理 (S5) 成立。

**活动 7.1.3：具有修改的加法规则的有序对 (U7-LO1)**

令$V$为所有有序实数对$(x,y)$与操作

$$
(x_1,y_1) \oplus (x_2,y_2) = (x_1,0) \quad\text{and}\quad c \odot (x,y) = (cx,cy)
$$

的集合。证明 $V$ 不是  vector space 。

??? success "解答"

    集合$V$以及在其上定义的操作无法满足公理（A4），即$V$中不存在 zero vector 。由于$(x_1,y_1) \oplus (x_2,y_2) = (x_1,0)$，对于所有有序对$(x,y)$，不可能存在 vector $(x_0,y_0)$使得$(x_0,y_0) \oplus (x,y) = (x,y)$。

    请注意，这并不是 $V$ 无法满足的唯一公理。 $V$ 也无法满足公理 (A2)、(A5) 和 (S3)。验证这些公理中的任何一个不成立也将构成$V$不是 vector space 的有效论证。但一个有效的论证只需要检查其中一个公理是否成立。

**活动 7.1.4：具有修改的  scaling  规则的有序对 (U7-LO1)**

令$V$为所有有序实数对$(x,y)$与操作

$$
(x_1,y_1) \oplus (x_2,y_2) = (x_1 + x_2, y_1 + y_2) \quad\text{and}\quad c \odot (x,y) = (cx,y)
$$

的集合。证明 $V$ 不是  vector space 。

??? success "解答"

    在这个加法和乘法的定义下，$V$不能满足公理（S3）。我们计算

    $$
    (a + b) \odot (x,y) = ((a + b)x, y)
    $$

    和

    $$
    \left(a \odot (x,y) \right) \oplus \left( b \odot (x,y) \right) = (ax,y) \oplus (bx,y) = (ax + bx, 2y)
    $$

    如果$y \neq 0$，则两个元组将不相等。因此，通过取 $a = b = 1$ 和 $(x,y) = (0,1)$ 可以得到表明 Axiom (S3) 失败的特定反例。然后

    $$
    (1 + 1) \odot (0,1) = (0,1)
    $$

    而

    $$
    (1 \odot (0,1)) \oplus (1 \odot (0,1)) = (0,2)
    $$

    这两个量显然不相等，这表明 Axiom (S3) 失败，因此 $V$ 不是  vector space 。

**活动 7.1.5：非负实数运算 (U7-LO1)**

设$V$为所有非负实数的集合，定义 vector addition 为

$$
\mathbf{v} \oplus \mathbf{u} = |\mathbf{v} - \mathbf{u}|
$$

scalar multiplication 为

$$
a \odot \mathbf{v} = |a| \mathbf{v}
$$

这个结构是否形成 vector space ？

??? success "解答"

    根据这个定义，加法不是结合律，即 Axiom (A3) 失败。为了找到反例，我们必须找到$V$的三个元素使得

    $$
    |x - |y - z|| \neq ||x - y| - z|
    $$

    我们不妨先简单地猜测这个方程不成立的一些值，因为通常如果代数恒等式不成立，那么它对于大多数输入也无法成立。选择 $x = 3$、$y = 1$ 和 $z = 2$。然后

    $$
    (x \oplus y) \oplus z = ||3 - 1| - 2| = |2 - 2| = 0
    $$

    而

    $$
    x \oplus (y \oplus z) = |3 - |1 - 2|| = |3 - 1| = 2
    $$

    因此，我们发现了一个特殊的反例，表明加法不具有结合律。

下面我们列出了关于任意  vector space  中加法和乘法相互作用的几个事实。

**定理 7.1.1**

设 $V$ 是一个  vector space 。对于任意 $\mathbf{v} \in V$ 和 $a \in \mathbb{R}$，都有以下性质：
- $0 \mathbf{u} = \mathbf{0}$.

- $a \mathbf{0} = \mathbf{0}$.

- 如果$a \mathbf{v} = \mathbf{0}$，则$a = 0$或$\mathbf{v} = \mathbf{0}$。

- $(-1) \mathbf{v} = - \mathbf{v}$.

- $(-a) \mathbf{v} = -(a\mathbf{v}) = a (-\mathbf{v})$.

重点不是每个 vector 看起来都像一个箭头。关键是，相同的代数规则让我们可以在对象为  matrices  或多项式的设置中重用  span 、独立性、 bases 、 coordinates 、 dimension  和  linear maps 。
