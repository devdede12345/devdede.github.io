## Mathematical Quick Reference {#mathematical-quick-reference}

### Functions, Domains, and Local Language {#functions-domains-and-local-language}

**Function Types**: scalar-valued function 的形式为 $f:D\subseteq\mathbb R^n\to\mathbb R$； vector-valued function $F:D\subseteq\mathbb R^n\to\mathbb R^m$ 具有 scalar component function $F_1,\ldots,F_m$。 domain 由允许的输入组成， range 由实际能够取得的输出组成。

**Graph and Level Set**: $f$ 的 graph 是 $\{(\mathbf x,f(\mathbf x)):\mathbf x\in D\}$；对应 $c$ 的 level set 是 $\{\mathbf x\in D:f(\mathbf x)=c\}$。

**Open Ball**: $B_r(\mathbf a)=\{\mathbf x:\|\mathbf x-\mathbf a\|\lt r\}$，其中 $r>0$。如果以某点为中心的一个球完全包含在 $D$ 中，该点就是 $D$ 的 interior point；如果以该点为中心的每个球都同时与 $D$ 及其补集相交，该点就是 boundary point。包含全部 boundary point 的集合是 closed set，包含在某个球中的集合是 bounded set。

**Limit**: 在 domain 的聚点处，当 $\mathbf x\to\mathbf a$ 时有 $F(\mathbf x)\to\mathbf L$，意思是：对任意 $\epsilon>0$，都存在 $\delta>0$，使得 

$$
\mathbf x\in D,\quad 0\lt\|\mathbf x-\mathbf a\|\lt\delta\quad\Longrightarrow\quad\|F(\mathbf x)-\mathbf L\|\lt\epsilon.
$$

vector-valued function 的 limit 逐 component 计算。若两条路径得到不同的 limit，就能证明 limit 不存在；但有限几条路径的 limit 相同，并不能证明 limit 存在。

**Continuity**: 在聚点 $\mathbf a\in D$ 处，连续意味着 $\lim_{\mathbf x\to\mathbf a}F(\mathbf x)=F(\mathbf a)$，其中输入限制在 $D$ 内。在 domain 的孤立点处， continuity 自动成立。

### Derivatives and their dimensions {#derivatives-and-their-dimensions}

**One-parameter Derivative**: 对于 $\mathbf r(t)=(r_1(t),\ldots,r_m(t))$，有 

$$
\mathbf r'(t)=(r_1'(t),\ldots,r_m'(t)).
$$

当 $\mathbf r'(a)\neq\mathbf0$ 时，切线为 $\mathbf r(a)+s\mathbf r'(a)$。

**Partial Derivative**: 固定其余 coordinate，只对一个 coordinate 求导：

$$
f_{x_j}(\mathbf a)=\lim_{h\to0}\frac{f(\mathbf a+h\mathbf e_j)-f(\mathbf a)}h.
$$



**Gradient and Hessian**: 对于有 $n$ 个变量的 scalar-valued function，

$$
\nabla f=\begin{bmatrix}f_{x_1}\\\vdots\\f_{x_n}\end{bmatrix}\in\mathbb R^n,\qquad H_f=[f_{x_i x_j}]\in\mathbb R^{n\times n}.
$$

这里 $f_{x_i x_j}=(f_{x_i})_{x_j}$ 的约定是先对 $x_i$ 求导，再对 $x_j$ 求导。因此只要相应元素存在，就有 $H_f=J_{\nabla f}$。连续的 second partial derivative 保证 mixed partial derivative 相等，从而 Hessian matrix 对称。

**Jacobian Matrix**: 对于 $F:\mathbb R^n\to\mathbb R^m$，

$$
J_F=\left[\frac{\partial F_i}{\partial x_j}\right]\in\mathbb R^{m\times n},\qquad J_f=(\nabla f)^T.
$$

第 $i$ 行是对 component $F_i$ 求导；第 $j$  column 描述沿输入方向 $\mathbf e_j$ 的变化。

### Differentiability and Local Approximation {#differentiability-and-local-approximation}

**Differentiability**: 在 interior point $\mathbf a$ 处， derivative 是一个 linear map，其误差相对于输入变化趋于零：

$$
\lim_{\mathbf h\to\mathbf0}\frac{\|F(\mathbf a+\mathbf h)-F(\mathbf a)-J_F(\mathbf a)\mathbf h\|}{\|\mathbf h\|}=0.
$$

$\mathbf a$ 附近的 first partial derivatives连续是 differentiable 的充分条件；仅有 partial derivative 存在并不足够。

**Local Prediction**: 

$$
F(\mathbf a+\mathbf h)\approx F(\mathbf a)+J_F(\mathbf a)\mathbf h,\qquad f(\mathbf a+\mathbf h)\approx f(\mathbf a)+\nabla f(\mathbf a)\cdot\mathbf h.
$$



**Tangent Plane**: 若 $z=f(x,y)$ 在 $(a,b)$ 处 differentiable，则 

$$
z=f(a,b)+f_x(a,b)(x-a)+f_y(a,b)(y-b).
$$

一个 normal vector 为 $(f_x(a,b),f_y(a,b),-1)$。

**First-order Zero Change**: 若 $\mathbf h\in\operatorname{null}(J_F(\mathbf a))$，预测的一阶输出变化为零，但实际的 nonlinear 变化不一定为零。

### Chain rule {#chain-rule}

**Composition**: 若 $G:\mathbb R^n\to\mathbb R^p$ 在 $\mathbf a$ 处 differentiable，且 $F:\mathbb R^p\to\mathbb R^m$ 在 $G(\mathbf a)$ 处 differentiable，则 

$$
J_{F\circ G}(\mathbf a)=J_F(G(\mathbf a))J_G(\mathbf a).
$$

matrix dimension 为 $(m\times p)(p\times n)=m\times n$；右侧的因子先作用。

**Scalar Function along a Curve**: 

$$
\frac{d}{dt}f(\mathbf r(t))=\nabla f(\mathbf r(t))\cdot\mathbf r'(t).
$$



### Directional Change and First-order Optimization {#directional-change-and-first-order-optimization}

**Directional Derivative**: 对于 differentiable function $f$ 和单位方向 $\mathbf u$，

$$
D_{\mathbf u}f(\mathbf a)=\nabla f(\mathbf a)\cdot\mathbf u.
$$

使用公式前，先对给定的 nonzero direction vector 进行 normalization。

**Steepest Directions**: 若 $\nabla f(\mathbf a)\neq\mathbf0$，最大与最小 directional derivative 分别为 $\|\nabla f(\mathbf a)\|$ 和 $-\|\nabla f(\mathbf a)\|$，在方向 $\pm\nabla f(\mathbf a)/\|\nabla f(\mathbf a)\|$ 上取得。若 gradient 为零，则所有 directional derivative 都为零。

**Local and Global Extrema**: local minimum 与某个邻域内的 function 值比较， global minimum 与整个 domain 内的 function 值比较。将不等号反向，即得到最大值的定义。

**Critical Point**: 本书将满足 $\nabla f(\mathbf a)=\mathbf0$ 的 differentiable 点 $\mathbf a$ 称为 critical point。 domain interior point 处 differentiable 的 local extremum 一定是 critical point，但反过来并不成立。 boundary point 和不 differentiable 点需要另外检查。

**Gradient Descent**: 从 $\mathbf x_0$ 出发，取 step size $\alpha>0$，按 

$$
\mathbf x_{k+1}=\mathbf x_k-\alpha\nabla f(\mathbf x_k).
$$

更新。对于 gradient 非零的 differentiable function，沿负 gradient 方向迈出足够小的一步会使 function 值减小。但任意选取的 step size 并不保证 function 值下降，也不保证收敛。

### From vector predictions to scalar error {#from-vector-predictions-to-scalar-error}

固定 $X\in\mathbb R^{m\times n}$ 和 $\mathbf y\in\mathbb R^m$，改变权重 $\mathbf w\in\mathbb R^n$。预测 $P(\mathbf w)=X\mathbf w$ 是 linear 的， residual $R(\mathbf w)=X\mathbf w-\mathbf y$ 是 affine 的，误差平方和是 scalar-valued function 

$$
\mathcal L(\mathbf w)=R(\mathbf w)^TR(\mathbf w),\qquad \nabla\mathcal L(\mathbf w)=2X^T(X\mathbf w-\mathbf y),\qquad H_{\mathcal L}=2X^TX.
$$

chain rule 给出 row vector $J_{\mathcal L}=2R^TX$，将它 transpose 就得到 gradient column vector。这里使用平方和，没有取平均，也没有乘以 $1/2$。

**Local and Exact Changes**: 一阶预测为 $\nabla\mathcal L(\mathbf w)\cdot\mathbf h$；对这个 loss function，还有精确等式 

$$
\mathcal L(\mathbf w+\mathbf h)=\mathcal L(\mathbf w)+\nabla\mathcal L(\mathbf w)\cdot\mathbf h+\|X\mathbf h\|^2.
$$

沿 $\mathbf w(t)=\mathbf w_0+t\mathbf d$ 的 derivative 为 $\nabla\mathcal L(\mathbf w(t))\cdot\mathbf d$，它是相对于 $t$ 的变化率，不要求 $\mathbf d$ 具有单位长度。

**Levels and Redundant Features**: 损失相同意味着 residual 长度的平方相同，不一定意味着预测相同。零损失可以达到，当且仅当 $X\mathbf w=\mathbf y$ 相容。若 $X\mathbf z=\mathbf0$，那么对每个 $t$，沿 $\mathbf w+t\mathbf z$ 的预测、 residual 和损失都完全不变。这比仅在某点的 directional derivative 为零更强。见[参数空间中的等误差曲线 (U3-LO1)](3-1.md#act-u3-prediction-loss-level-curves)和[冗余特征给出了损失的平坦方向（U3-LO6、U2-LO6）](3-6.md#act-u3-prediction-loss-flat-direction)。

在三个观测值的例子中，$\mathcal L(1,1)=1$，且 $\nabla\mathcal L(1,1)=(0,-2)$。取 $\alpha=1/10$ 的一次迭代到达 $(1,6/5)$，损失为 $17/25$，新的 gradient 仍非零。损失下降意味着取得进展，并不自动证明已经到达最小值。

### Reading the Symbolic Computations {#reading-the-symbolic-computations}

`sp.diff(f, x)` 和 `sp.diff(f, x, 2)` 用于计算一阶与重复 partial derivative。混合求导 `sp.diff(f, x, y)` 和 `sp.diff(f, y, x)` 分别计算 $f_{xy}$ 和 $f_{yx}$。用 `sp.Matrix([sp.diff(f, x), sp.diff(f, y)])` 构造 gradient column vector，用 `sp.hessian(f, (x, y))` 求 Hessian matrix，用 `F.jacobian([x, y])` 求 vector-valued map的 Jacobian matrix。按本书的下标约定，只要相应元素存在，就有 $J_{\nabla f}=H_f$。

先求导，再用 `.subs` 在某点代入求值。用 `sp.Rational` 表示精确分数，用 `sp.simplify` 检查符号表达式之差。 chain rule 乘积中的外层 derivative 需要在内层输出处求值； gradient descent 每一步都要在新点重新计算 gradient。SymPy matrix multiplication 使用 `*`，NumPy 数组的 matrix multiplication 使用 `@`。例子与 dimension 见[SymPy 速查](app-computation-11.md#appcomp-sympy)。

## Common mistakes {#common-mistakes}

混淆 domain 与 range；试图用少数几条路径证明多元 limit 存在；认为 partial derivative 存在就保证 differentiable；把局部近似当作精确等式；混淆 $\mathbf h$ 与 $\mathbf a+\mathbf h$；颠倒 chain rule 中 matrix 的乘法顺序，或在错误的点代入；使用非单位方向；把每个 critical point 都当作极值点；忽略 boundary；认为 gradient descent 的每一步都会使 function 值下降。

代码中，若先代入完整的点再求导，就会消除表达式对变量的依赖。 gradient column vector 不等于 scalar-valued function 的 Jacobian row vector。在预测误差的例子中，损失相同不一定意味着预测相同；一个点的某个 partial derivative 为零不一定意味着整条线上 function 不变；一阶预测的变化量也不是新的损失值。每次更新后都要重新计算 gradient。
