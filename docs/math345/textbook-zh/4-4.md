## 从 Gram–Schmidt 到 $QR$ {#gramschmidt-qr}

[Gram–Schmidt 算法](4-2.md#alg-u4-gram-schmidt) 从左到右处理 matrix 的 linearly independent column。它构造 orthonormal vector $\mathbf{q}_1,\ldots,\mathbf{q}_n$ 并记录 coefficient $r_{ij}$；这些量可以组成 matrix 分解。

设 

$$
A
        =
        \begin{bmatrix}
        \mathbf{a}_1&\mathbf{a}_2&\cdots&\mathbf{a}_n
        \end{bmatrix}.
$$


在第 $j$  column，Gram–Schmidt 算法计算 

$$
\begin{gathered}
        r_{ij}=\mathbf{q}_i^T\mathbf{a}_j,
        \qquad i\lt j,\\[0.6em]
        \mathbf{p}_j
        =
        \sum_{i\lt j}
        r_{ij}\mathbf{q}_i,
        \qquad
        \mathbf{v}_j
        =
        \mathbf{a}_j-\mathbf{p}_j,\\
        r_{jj}
        =
        \|\mathbf{v}_j\|,
        \qquad
        \mathbf{q}_j
        =
        \frac{\mathbf{v}_j}{r_{jj}}.
        \end{gathered}
$$


由于 

$$
\mathbf{v}_j
        =
        r_{jj}\mathbf{q}_j,
$$

可重构原 matrix 的 column：

$$
\mathbf{a}_j
        =
        \mathbf{p}_j+\mathbf{v}_j
        =
        \sum_{i\lt j}
        r_{ij}\mathbf{q}_i
        +
        r_{jj}\mathbf{q}_j
        =
        \sum_{i\leq j}
        r_{ij}\mathbf{q}_i.
$$


因此，第 $j$  column 仅用到 $\mathbf{q}_1,\ldots,\mathbf{q}_j$。

把 orthonormal vector 收集为 

$$
Q
        =
        \begin{bmatrix}
        \mathbf{q}_1&\mathbf{q}_2&\cdots&\mathbf{q}_n
        \end{bmatrix}
$$

coefficient 收集为 

$$
R
        =
        \begin{bmatrix}
        r_{11}& r_{12}&\cdots& r_{1n}\\
        0& r_{22}&\cdots& r_{2n}\\
        \vdots&\ddots&\ddots&\vdots\\
        0&\cdots&0& r_{nn}
        \end{bmatrix}.
$$


以上逐 column 方程合成一个 matrix 方程 

$$
A=QR.
$$


$R$ 对角线下方的零记录了算法的构造次序：第 $j$  column 只使用截至第 $j$ 步构造的方向。


<a id="subsec-qr-definition-3"></a>

**定义 4.4.1：约化 $QR$ 分解（Reduced QR Factorization）**


<a id="subsec-qr-definition-3-1"></a>

设 $A$ 是 具有 full column rank 的 $m\times n$  matrix。$A$ 的约化 $QR$ 分解，是满足以下条件的分解 

$$
A=QR,
$$

：


- $Q$ 是 columns 构成 orthonormal set 的 $m\times n$  matrix；

- $R$ 是 invertible 的 $n\times n$  upper triangular matrix。


本章使用的 Gram–Schmidt 约定使 $R$ 的对角元为正：

$$
r_{jj}=\|\mathbf{v}_j\|>0.
$$


<a id="subsec-qr-definition-7"></a>

**活动 4.4.1：解读 $Q^T Q$（U4-LO1）**


<a id="subsec-qr-definition-7-1"></a>

设 

$$
Q
            =
            \begin{bmatrix}
            1/\sqrt{3}&1/\sqrt{6}\\
            1/\sqrt{3}&-2/\sqrt{6}\\

3. 计算 $Q^TQ$。

4. $Q^TQ$ 的 $(i,j)$ 元表示什么？

5. 解释为什么 

$$
Q^TQ=I_2
$$

能用 matrix 形式检查 $Q$ 的 columns 构成 orthonormal set。


<a id="subsec-qr-definition-7-2"></a>

??? success "解答"

    有 

    $$
    \|\mathbf{q}_1\|^2
                =
                \frac13+\frac13+\frac13
                =
                1
    $$

     和 

    $$
    \|\mathbf{q}_2\|^2
                =
                \frac16+\frac46+\frac16
                =
                1.
    $$

    

    另外，

    $$
    \mathbf{q}_1^T\mathbf{q}_2
                =
                \frac{1}{\sqrt{18}}
                -
                \frac{2}{\sqrt{18}}
                +
                \frac{1}{\sqrt{18}}
                =
                0.
    $$

    

    因此 

    $$
    Q^TQ
                =
                \begin{bmatrix}
                \mathbf{q}_1^T\mathbf{q}_1&
                \mathbf{q}_1^T\mathbf{q}_2\\
                \mathbf{q}_2^T\mathbf{q}_1&
                \mathbf{q}_2^T\mathbf{q}_2
                \end{bmatrix}
                =
                \begin{bmatrix}
                1&0\\
                0&1
                \end{bmatrix}
                =
                I_2.
    $$

    

    $Q^TQ$ 的 $(i,j)$ 元是 dot product $\mathbf{q}_i^T\mathbf{q}_j$。对角元检查单位长度，非对角元检查 orthogonality。


<a id="subsec-qr-definition-10"></a>

**定理 4.4.1：Gram–Schmidt 生成 $QR$**


<a id="subsec-qr-definition-10-1"></a>

每个 具有 full column rank 的 $m\times n$  matrix $A$ 都有约化 $QR$ 分解 

$$
A=QR
$$

其中 $Q$ 的 columns 构成 orthonormal set，$R$ 是对角元为正的 upper triangular matrix。


<a id="subsec-qr-definition-10-2"></a>

??? info "证明"

    对 column 

    $$
    \mathbf{a}_1,\ldots,\mathbf{a}_n.
    $$

     应用 [Gram–Schmidt 算法](4-2.md#alg-u4-gram-schmidt)

    在第 $j$ 步，算法给出 

    $$
    \mathbf{a}_j
                =
                \sum_{i\leq j}
                r_{ij}\mathbf{q}_i.
    $$

    

    把这些方程逐 column 组合，得到 

    $$
    A=QR.
    $$

    

    $Q$ 的 columns 构成 orthonormal set。$i\leq j$ 保证 $R$ 为 upper triangular matrix，而输入 columns 彼此 linearly independent 保证 

    $$
    r_{jj}
                =
                \|\mathbf{v}_j\|
                >
                0
    $$

    <!-- punctuation omitted -->
<a id="subsec-qr-definition-13"></a>

**推论 4.4.1：square matrix 情形（Square Case）**


<a id="subsec-qr-definition-13-1"></a>

每个 invertible square matrix 都有 $QR$ 分解 

$$
A=QR,
$$

其中 $Q$ 是 [ orthogonal matrix ](2-5.md#def-4-2-orthogonal)，$R$ 是对角元为正的 upper triangular matrix。

??? info "证明"

     invertible square matrix 的 columns 彼此 linearly independent，应用“[Gram–Schmidt 生成 QR](4-4.md#subsec-qr-definition-10)”。由于 $Q$ 为 square matrix 且 columns 构成 orthonormal set，有 

    $$
    Q^TQ=QQ^T=I.
    $$

    因此 $Q$ 是 orthogonal matrix。

<a id="warn-u4-rectangular-q"></a>

**注意：rectangular matrix 的 $Q$**

对满足 $m\gt n$ 的 $m\times n$  matrix，约化 $QR$ 分解中的 $Q$  columns 构成 orthonormal set，因此 

$$
Q^TQ=I_n.
$$


但 $Q$ 不是 square matrix，一般有 

$$
QQ^T\neq I_m.
$$


实际上，

$$
QQ^T\mathbf{b}
          =
          \operatorname{proj}_{\operatorname{col}(Q)}(\mathbf{b})
          =
          \operatorname{proj}_{\operatorname{col}(A)}(\mathbf{b}).
$$


确实，$Q^T\mathbf{b}$ 的各 component 是 dot product $\mathbf{q}_i\cdot\mathbf{b}$。乘以 $Q$ 形成其 column 的相应 linear combination：

$$
QQ^T\mathbf{b}
          =
          \sum_{i=1}^n(\mathbf{q}_i\cdot\mathbf{b})\mathbf{q}_i
          =
          \operatorname{proj}_{\operatorname{col}(Q)}(\mathbf{b}).
$$

最后一个等式来自 [ projection theorem ](4-2.md#thm-6-2projection)，因为 $Q$ 的 column 构成 $\operatorname{col}(Q)$ 的 orthonormal basis。

另外，$A=QR$ 把 $A$ 的每列表示为 $Q$ 的 column 的 linear combination。由于 $R$  invertible，$Q=AR^{-1}$ 给出反向包含关系。因此 $\operatorname{col}(Q)=\operatorname{col}(A)$，两种 projection 相同。

**注意：$QR$ 分解中的符号**

正对角元约定固定了 Gram–Schmidt 分解中的符号。不要求此约定时，可以把一个 column $\mathbf{q}_j$ 换成 $-\mathbf{q}_j$，同时把 $R$ 的第 $j$ 行取负，乘积 $QR$ 不变。因此，数值软件给出的 $Q$、$R$ 可能与手算符号不同。应检查 $Q^TQ=I$ 和 $QR=A$，而不是要求每个元素符号相同。

## 用 $QR$ 求 least squares {#qr_1}

[ least squares 与 normal equations ](4-3.md#thm-normal-equations-residual-orthogonality) 中的 normal equations，提供了从 $QR$ 分解求 least-squares solution 的直接途径。

假设 

$$
A=QR
$$

是约化 $QR$ 分解。 normal equations 为 

$$
A^TA\widehat{\mathbf{x}}
        =
        A^T\mathbf{b}.
$$


代入 $A=QR$ 得 

$$
R^TQ^TQR\widehat{\mathbf{x}}
        =
        R^TQ^T\mathbf{b}.
$$


由于 

$$
Q^TQ=I,
$$

上式变为 

$$
R^TR\widehat{\mathbf{x}}
        =
        R^TQ^T\mathbf{b}.
$$


matrix $R$  invertible，因此 $R^T$  invertible。消去 $R^T$ 得 

$$
R\widehat{\mathbf{x}}
        =
        Q^T\mathbf{b}.
$$


下一活动说明，为什么可以用第二章 [ back-substitution 例题](2-2.md#ex-u2-back-substitution) 中介绍的 back-substitution 法，轻松求解这个上三角方程组。


<a id="subsec-qr-definition-8"></a>

**活动 4.4.4：back-substitution （Back-substitution，U2-LO2）**


<a id="subsec-qr-definition-8-1"></a>

求解 

$$
R\mathbf{x}
            =
            \mathbf{y},
$$

其中 

$$
R
            =
            \begin{bmatrix}
            4&2&7\\
            0&3&5\\
            0&0&2
            \end{bmatrix},
            \qquad
            \mathbf{y}
            =
            \begin{bmatrix}
            29\\
            21\\
            6
            \end{bmatrix}.
$$


从最后一个方程开始，向上逐步求解。


<a id="subsec-qr-definition-8-2"></a>

??? success "解答"

    最后一个方程给出 

    $$
    2x_3=6,
                \qquad
                x_3=3.
    $$

    

    第二个方程给出 

    $$
    3x_2+5x_3=21,
    $$

    所以 

    $$
    3x_2+15=21,
                \qquad
                x_2=2.
    $$

    

    第一个方程给出 

    $$
    4x_1+2x_2+7x_3=29,
    $$

    所以 

    $$
    4x_1+4+21=29,
                \qquad
                x_1=1.
    $$

    

    因此 

    $$
    \mathbf{x}
                =
                \begin{bmatrix}
                1\\
                2\\
                3
                \end{bmatrix}.
    $$

    


<a id="alg-u4-qr-least-squares"></a>

**算法 4.4.1：用 $QR$ 求 least squares **

输入： 具有 full column rank 的 $m\times n$  matrix $A$，以及 vector $\mathbf{b}\in\mathbb{R}^m$。


1. 计算约化 $QR$ 分解 

$$
A=QR.
$$


2. 计算 

$$
\mathbf{y}=Q^T\mathbf{b}.
$$


3. 通过 back-substitution 求解上三角方程组 

$$
R\widehat{\mathbf{x}}=\mathbf{y}
$$

<!-- punctuation omitted -->
输出：vector $\widehat{\mathbf{x}}$ 为 least squares coefficient vector， fitted vector 为 

$$
A\widehat{\mathbf{x}}
            =
            QR\widehat{\mathbf{x}}
            =
            QQ^T\mathbf{b}.
$$


该方法不必构造 $A^TA$ 或计算 inverse matrix：已知 $Q$、$R$ 后，只需 dot product 和 back-substitution。如果 $A$ 固定而 $\mathbf{b}$ 改变，每个新的右端 vector 都能复用同一分解。浮点计算中，数值稳定的 $QR$ 算法也可能比 normal equations 求解更准确，尤其当 $A$ 的 column 近乎 linearly dependent 时。


<a id="act-u4-qr-least-squares-by-hand"></a>

**活动 4.4.5：用 $QR$ 求解 least squares （U4-LO2，U4-LO6）**

用 $QR$，为 [为三个数据点拟合直线（U4-LO4，U4-LO5）](4-3.md#act-u4-fit-line-three-points) 中的数据点 

$$
(0,1),\qquad(1,2),\qquad(2,2)
$$

拟合直线 $y=c_0+c_1t$。 design matrix 与数据 vector 为 

$$
X=\begin{bmatrix}
            1&0\\
            1&1\\
            1&2
            \end{bmatrix},
            \qquad
            \mathbf{y}=\begin{bmatrix}1\\2\\2\end{bmatrix}.
$$


1. 对 $X$ 的 column 应用 Gram–Schmidt，求约化分解 $X=QR$，并使 $R$ 的对角元为正。

2. 计算 $Q^T\mathbf{y}$。

3. back-substitution 求解 $R\widehat{\mathbf{c}}=Q^T\mathbf{y}$，写出拟合直线。


??? success "解答"

    写成 $X=[\mathbf{a}_1\ \mathbf{a}_2]$。第一个 column 给出 

    $$
    r_{11}=\|\mathbf{a}_1\|=\sqrt{3},
                \qquad
                \mathbf{q}_1=\frac{1}{\sqrt{3}}\begin{bmatrix}1\\1\\1\end{bmatrix}.
    $$

    

    对第二个 column，

    $$
    r_{12}=\mathbf{q}_1^T\mathbf{a}_2
                =\frac{0+1+2}{\sqrt{3}}=\sqrt{3}.
    $$

    减去沿 $\mathbf{q}_1$ 的 component 得 

    $$
    \mathbf{v}_2
                =\mathbf{a}_2-r_{12}\mathbf{q}_1
                =\begin{bmatrix}0\\1\\2\end{bmatrix}
                -\begin{bmatrix}1\\1\\1\end{bmatrix}
                =\begin{bmatrix}-1\\0\\1\end{bmatrix}.
    $$

    所以 

    $$
    r_{22}=\|\mathbf{v}_2\|=\sqrt{2},
                \qquad
                \mathbf{q}_2=\frac{1}{\sqrt{2}}\begin{bmatrix}-1\\0\\1\end{bmatrix}.
    $$

    

    因此约化分解的两个因子为 

    $$
    Q=\begin{bmatrix}
                1/\sqrt{3}&-1/\sqrt{2}\\
                1/\sqrt{3}&0\\
                1/\sqrt{3}&1/\sqrt{2}
                \end{bmatrix},
                \qquad
                R=\begin{bmatrix}
                \sqrt{3}&\sqrt{3}\\
                0&\sqrt{2}
                \end{bmatrix}.
    $$

    

    变换后的右端 vector 为 

    $$
    Q^T\mathbf{y}
                =\begin{bmatrix}
                \mathbf{q}_1^T\mathbf{y}\\
                \mathbf{q}_2^T\mathbf{y}
                \end{bmatrix}
                =\begin{bmatrix}
                (1+2+2)/\sqrt{3}\\
                (-1+0+2)/\sqrt{2}
                \end{bmatrix}
                =\begin{bmatrix}
                5/\sqrt{3}\\
                1/\sqrt{2}
                \end{bmatrix}.
    $$

    

    $R\widehat{\mathbf{c}}=Q^T\mathbf{y}$ 的最后一个方程给出 

    $$
    \sqrt{2}\,\widehat c_1=\frac{1}{\sqrt{2}},
                \qquad
                \widehat c_1=\frac12.
    $$

    代入第一个方程得 

    $$
    \sqrt{3}\,\widehat c_0+\sqrt{3}\left(\frac12\right)
                =\frac{5}{\sqrt{3}},
    $$

    所以 

    $$
    \widehat c_0=\frac53-\frac12=\frac76.
    $$

    

    因此 

    $$
    \widehat{\mathbf{c}}=\begin{bmatrix}7/6\\1/2\end{bmatrix},
    $$

    拟合直线为 

    $$
    y=\frac76+\frac12t.
    $$

    


<a id="act-u4-qr-code-reading"></a>

**活动 4.4.6：通过代码用 $QR$ 求 least squares （U4-LO6，U4-LO7）**


<a id="act-u4-qr-code-reading-2"></a>

以下代码重复 [求解 least squares ](4-4.md#act-u4-qr-least-squares-by-hand) 中的 $QR$  least squares 计算。

function `np.linalg.qr` 返回两个因子，赋值语句将其存入 `Q`、`R`：`Q` 的 columns 构成 orthonormal set，`R` 为 upper triangular matrix，两者乘积为 `X`。选项 `mode="reduced"` 只保留 span `X`  column space 所需的 `Q` 的 column，以及对应的 square matrix 因子 `R`，而不把 `Q` 扩充成方形 orthogonal matrix。

表达式 `np.eye(Q.shape[1])` 构造阶数等于 `Q`  column 数的 identity matrix，本例中是 $2\times2$  identity matrix。

function `np.linalg.solve` 直接求解 square matrix 方程组，不显式求 coefficient matrix 的逆。优先使用它而不是先求逆再相乘，可以避免不必要的计算和额外 roundoff error。


```python
import numpy as np

t = np.array([0.0, 1.0, 2.0])
y = np.array([1.0, 2.0, 2.0])

X = np.column_stack([np.ones_like(t), t])
```

    因为 `X` 的形状为 `(3, 2)`，约化 $QR$ 得到


    ```python
    Q.shape == (3, 2)
    R.shape == (2, 2)
    ```

    表达式


    ```python
    Q.T @ Q
    ```

    检查 `Q` 的 column 是否 orthonormal。表达式


    ```python
    Q @ R
    ```

    检查分解因子是否重构 `X`。

     vector 


    ```python
    Q.T @ y
    ```

    是约化方程组 

    $$
    R\widehat{\mathbf{c}}
                =
                Q^T\mathbf{y}.
    $$

     的右端 vector $Q^T\mathbf{y}$

     matrix `R` 是 invertible 上三角 square matrix，因此代码用 `np.linalg.solve` 求解这个方程组。

    两种方法计算相同的 least squares coefficient vector，因此


    ```python
    c_qr
    ```

    以及


    ```python
    c_lstsq
    ```

    都应接近


    ```python
    array([1.16666667, 0.5])
    ```

    最后的 `np.allclose` 检查应返回 `True`。

    两者一致不意味着 

    $$
    X\mathbf{c}=\mathbf{y}
    $$

     有精确解，[回归活动](4-3.md#act-u4-fit-line-three-points) 中的 residual 非零。

    合法的 $QR$ 分解允许同时改变 $Q$ 某一个 column 和 $R$ 对应 row 的符号。因此数值输出可以与手算符号不同，同时仍满足 

    $$
    Q^TQ=I
                \qquad\text{and}\qquad
                QR=X.
    $$
