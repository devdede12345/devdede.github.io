**活动 6.6.1：读取  PCA  计算 (U6-LO5)**

以下代码重复了[the activity “Principal directions of a small data set”](6-4.md#act-u6-pca-small-data-set)的一部分。


```python
import numpy as np

np.set_printoptions(precision=3, suppress=True)

X = np.array([
    [4.0, 3.0],
    [3.0, 4.0],
    [0.0, 1.0],
    [1.0, 0.0],
])

xbar = X.mean(axis=0)
Z = X - xbar
C = Z.T @ Z / len(X)

eigvals, V = np.linalg.eigh(C)
order = np.argsort(eigvals)[::-1]
eigvals = eigvals[order]
V = V[:, order]

v1 = V[:, 0]
scores1 = Z @ v1
Zhat1 = np.outer(scores1, v1)
R1 = Z - Zhat1

(
    xbar,
    C,
    eigvals,
    V,
    Zhat1,
    np.allclose(R1 @ v1, np.zeros(len(X))),
    V.T @ C @ V,
)
```

输出：


```text
(array([2., 2.]),
 array([[2.5, 2. ],
        [2. , 2.5]]),
 array([4.5, 0.5]),
 array([[ 0.707, -0.707],
        [ 0.707,  0.707]]),
 array([[ 1.5,  1.5],
        [ 1.5,  1.5],
        [-1.5, -1.5],
        [-1.5, -1.5]]),
 True,
 array([[4.5, 0. ],
        [0. , 0.5]]))
```

3. 为什么代码会反转 `np.linalg.eigh` 返回的顺序？

    ```python

    ```

<a id="sol-u6-recap-reading-pca-computation"></a>

??? success "解答"

    shapes  是 

    $$
    X\in\mathbb{R}^{4\times2},
                  \qquad
                  \bar{\mathbf{x}}\in\mathbb{R}^2,
                  \qquad
                  Z\in\mathbb{R}^{4\times2},
    $$


    $$
    C\in\mathbb{R}^{2\times2},
                  \qquad
                  V\in\mathbb{R}^{2\times2},
                  \qquad
                  \mathbf{t}_1\in\mathbb{R}^4,
                  \qquad
                  \widehat Z_1\in\mathbb{R}^{4\times2}.
    $$


    数组`xbar`存储样本平均值

    $$
    \bar{\mathbf{x}}
                  =
                  \begin{bmatrix}
                  2\\
                  2
                  \end{bmatrix},
    $$

    而`C`存储 covariance matrix 

    $$
    C=
                  \begin{bmatrix}
                  5/2 & 2\\
                  2 & 5/2
                  \end{bmatrix}.
    $$


    命令 `np.linalg.eigh` 按升序返回  eigenvalues 。逆转将最大的 eigenvalue 放在第一位。因此，$V$的第一个 column 是第一个 principal direction ，第二个 column 是第二个 principal direction 。

     vector  `scores1` 存储

    $$
    \mathbf{t}_1=Z\mathbf{v}_1.
    $$

     `Zhat1` 的 rows  是 centered data   vectors  的 projections  到

    $$
    \operatorname{span}\{\mathbf{v}_1\}.
    $$

      matrix  `R1` 存储相应的 reconstruction   residuals 。

    乘积 `R1 @ v1` 计算每个  residual   row  与 $\mathbf{v}_1$ 的  dot product 。值 `True` 检查每个  reconstruction   residual  在数值上垂直于第一个  principal direction 。

    将 $\mathbf{v}_1$ 替换为 $-\mathbf{v}_1$ 会反转其分数的符号。然而，

    $$
    (-t_i)(-\mathbf{v}_1)=t_i\mathbf{v}_1,
    $$

    因此投影点和 reconstruction  residuals 不会改变。principal axes是相同的。

    最终输出表明，主 coordinate system 中的 covariance 是

    $$
    V^TCV
                  =
                  \begin{bmatrix}
                  4.5 & 0\\
                  0 & 0.5
                  \end{bmatrix}.
    $$

    对角线条目是捕获的两个 principal directions 中的变化。第一个方向捕获总中心变化的 

    $$
    \frac{4.5}{4.5+0.5}
                  =
                  \frac9{10}
    $$

**活动 6.6.2：阅读 SVD  shapes （U6-LO6）**

以下代码计算减少的  SVD 。


```python
import numpy as np

A = np.array([[ 1., -1.],
              [-2.,  2.],
              [ 2., -2.]])

U, s, Vt = np.linalg.svd(A, full_matrices=False)

A.shape, U.shape, s.shape, Vt.shape
```

输出：


```text
((3, 2), (3, 2), (2,), (2, 2))
```


1. $A$的 shape 是多少？

2. 返回了多少个 singular values ？

3. 为什么`s.shape`等于`(2,)`而不是`(2, 2)`？

4. `Vt`代表什么 matrix ？

5. 在这个例子中`full_matrices=False`做了什么？

??? success "解答"

    matrix  $A$ 是 $3\times 2$。缩减后的 SVD 返回两个 singular values ，因为

    $$
    \min(3,2)=2.
    $$

    数组`s`仅存储$\Sigma$的对角线条目，而不是完整的 diagonal matrix ，因此其 shape 为`(2,)`。数组`Vt`代表$V^T$。对于`full_matrices=False`，NumPy 返回 reconstruction  所需的减少的 SVD   shapes ：

    $$
    U\in\mathbb R^{3\times 2},
                  \qquad
                  s\in\mathbb R^2,
                  \qquad
                  V^T\in\mathbb R^{2\times 2}.
    $$


<a id="act-u6-recap-singular-vector-identity"></a>

**活动 6.6.3：检查代码中的  singular - vector  身份 (U6-LO6)**

对于  SVD  

$$
A=U\Sigma V^T,
$$

 恒等式 

$$
A\mathbf{v}_i=\sigma_i\mathbf{u}_i
$$

 是读取因子的主要方法之一。以下代码检查此恒等式的对角线拉伸。


```python
A = np.array([[3., 0.],
              [0., 1.]])

U, s, Vt = np.linalg.svd(A, full_matrices=False)

i = 0
v = Vt.T[:, i]
lhs = A @ v
rhs = s[i] * U[:, i]

lhs, rhs, np.allclose(lhs, rhs)
```

输出：


```text
(array([3., 0.]), array([3., 0.]), True)
```


1. 哪个 vector 存储在`v`中？

2. `lhs`计算什么？

3. `rhs`计算什么？

4. 为什么`np.allclose(lhs, rhs)`返回`True`？

5. 此计算中出现哪个拉伸因子？

??? success "解答"

    vector `v`是第一个 right singular vector $\mathbf{v}_1$。数组 `lhs` 计算 $A\mathbf{v}_1$。数组`rhs`计算$\sigma_1\mathbf{u}_1$。值`True`表示数值计算符合

    $$
    A\mathbf{v}_1=\sigma_1\mathbf{u}_1.
    $$

    拉伸因子为

    $$
    \sigma_1=3.
    $$
