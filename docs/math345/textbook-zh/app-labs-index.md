**The notebooks are linked supplements to the textbook**: 它们并不是需要长时间带回家的编程作业。每个实验室的主要序列都是为课堂使用或指导复习而设计的。

实验室 U1： Vectors 、相似性、 Attention  和  Matrix  操作。第 1 单元。包括可选的热身部分和可选的延伸部分。重点：将简短的 NumPy 片段理解为数学符号；解释 norms 、 dot products 、 cosine similarity 、 attention 式 weighted averages 、 matrix - vector 产品、 matrix 产品、几何 matrix 动作和 affine maps 。**学习目标**： U1-LO1、U1-LO2、U1-LO3、U1-LO4、U1-LO5、U1-LO6、U1-LO7、U1-LO8。

实验室 U2：理解  Linear Map 。第 2 单元. 重点：将 NumPy 和 SymPy 的简短片段理解为数学符号；解释可达输出、 row reduction 、平面相交、齐次系统、遗忘方向、 rank 、空 vectors 、冗余 features 、行列式和 inverse 检查。**学习目标**： U2-LO1、U2-LO2、U2-LO3、U2-LO5、U2-LO6、U2-LO7。

实验室 U3： Jacobian   matrices  和  local linearization 。第 3 单元. 重点：阅读 SymPy 中的第一和第二偏音、梯度、Hessians 和  Jacobian   matrices ；遵循 vector 预测到 scalar 平方误差、局部 loss 预测、 chain rule 、下降步骤以及来自冗余 features 的精确平坦方向。包括可选的方形网格可视化和额外的模型块审查。**学习目标**： U3-LO1、U3-LO3、U3-LO4、U3-LO5、U3-LO6、U3-LO8、U3-LO9。

实验室 U4：回归为  Projection 。第 4 单元. 重点：设计 matrices 、 least squares 、 residual   orthogonality 。**学习目标**： U4-LO4、U4-LO5、U4-LO7。

实验室 U5： Hessian   eigenvalues 、 least squares ，并固定 nonlinear   features 。第五单元焦点：将 Hessian  eigenvalues 解释为曲率信息；连接 residual  orthogonality 、零 gradient 以及 least squares 的曲率；并安装一个  coefficient vector  来固定  nonlinear   features 。开场部分回顾了第 3 单元学习成果中的  gradient descent  和最后一层外积更新。 U3-LO6、U3-LO9、U5-LO5、U5-LO6、U5-LO7。

实验室 U6： Constraints 、 PCA  和  SVD 。第 6 单元. 重点：将简短的 NumPy 片段理解为数学符号；检查一个和多个 constraint Lagrange条件；将  quadratic forms  与  maximum stretch  连接；中心数据和表格 covariance ；计算 PCA 分数、重建、 residuals 和本金 coordinates ；将  PCA  与回归进行比较；将  PCA  与  SVD  连接；并从  SVD  中读取  rank  和four fundamental subspaces。**学习目标**： U6-LO2、U6-LO3、U6-LO4、U6-LO5、U6-LO6、U6-LO7。

实验室 U7：多项式逼近。单元 7. 重点：读取多项式  feature   matrices 、 least-squares   coefficients 、拟合值、 residual  检查、收缩区间  coefficients 、 Gram-Schmidt  检查以及采样平面拟合。比较泰勒、连续  least-squares  和采样  least-squares  近似值。**学习目标**： U7-LO3、U7-LO4、U7-LO5、U7-LO6。

变压器总结实验室：一个微小的  Attention  块。附录：变压器总结工作表。状态：可选扩展。焦点： token  matrices 、 attention 分数、掩码、加权值、 logits 和一个小 loss 。**学习目标**： U1-LO3、U1-LO6、U1-LO8、U3-LO7、U3-LO8。
