**活动 7.4.1： Feature   matrix  适用于  affine  合身 (U7-LO2)**

考虑代码：


```python
import numpy as np

xs = np.array([-1.0, -0.5, 0.0, 0.5, 1.0])
A = np.column_stack([np.ones_like(xs), xs])

A.shape, A
```


1. $A$ 有多少个 rows ？

2. $A$ 有多少个 columns ？

3. 第一个 column 代表什么？

4. 第二个 column 代表什么？

5. columns  代表什么多项式 subspace ？

??? success "解答"

    matrix  $A$ 有五个 rows ，每个样本点一个。它有两个 columns 。第一个 column 是采样常数 feature $1$。第二个 column 是采样的$x$- feature 。  columns  一起表示近似值  subspace  

    $$
    \mathcal P_{\le1}=\operatorname{span}\{1,x\}.
    $$

     A  coefficient vector  

    $$
    \mathbf c=
              \begin{bmatrix}
              c_0\\
              c_1
              \end{bmatrix}
    $$

     生成 

    $$
    q(x)=c_0+c_1x.
    $$

     的拟合值


<a id="act-u7-code-sampled-ls-residual"></a>

**活动 7.4.2：采样  least squares  和  residual   orthogonality （U7-LO4、U7-LO5）**

考虑代码：


```python
y = 1 + 2*xs + xs**2 + xs**3

c = np.linalg.lstsq(A, y, rcond=None)[0]
r = y - A @ c

c, A.T @ r
```

假设输出大约为


```python
(array([1.5 , 2.85]), array([0., 0.]))
```


1. coefficient vector 代表哪条线？

2. $A\mathbf c$存储什么？

3. $\mathbf r$存储什么？

4. `A.T @ r` 检查什么？

5. `A.T @ r`接近零是否意味着$\mathbf r=\mathbf0$？

??? success "解答"

    coefficient vector  

    $$
    \mathbf c\approx
              \begin{bmatrix}
              1.5\\
              2.85
              \end{bmatrix}
              =
              \begin{bmatrix}
              \frac32\\
              \frac{57}{20}
              \end{bmatrix}
    $$

     表示采样的 least-squares  线

    $$
    q_{\mathrm{sample}}(x)=\frac32+\frac{57}{20}x.
    $$

      vector  $A\mathbf c$ 存储采样点处的拟合值

    $$
    q_{\mathrm{sample}}(x_i)
    $$

    residual vector 

    $$
    \mathbf r=\mathbf y-A\mathbf c
    $$

    存储采样误差

    $$
    r_i=p(x_i)-q_{\mathrm{sample}}(x_i).
    $$

    计算`A.T @ r`检查 residual 与采样常数 feature 和采样$x$- feature 是否 orthogonal ：

    $$
    \sum_i r_i=0,
              \qquad
              \sum_i x_ir_i=0.
    $$

    这并不意味着$\mathbf r=\mathbf0$。这意味着  residual  是  orthogonal  的近似值  subspace 。

**活动 7.4.4：收缩区间 coefficients  (U7-LO5)**

考虑代码：


```python
ts = np.array([1.0, 0.5, 0.25, 0.125])

x2_const = ts**2 / 3
x3_slope = 3*ts**2 / 5

x2_const, x3_slope
```


1. `x2_const` 来自哪个多项式？

2. `x3_slope` 来自哪个多项式？

3. 两个数组都为 $t\to0$ 会发生什么？

4. 这如何连接到 Taylor approximation ？

??? success "解答"

    数组`x2_const`包含$L^2[-t,t]$- projection 、

    $$
    P_t(x^2)=\frac{t^2}{3}
    $$

    到$\operatorname{span}\{1,x\}$中的常量。数组 `x3_slope` 包含  projection  

    $$
    P_t(x^3)=\frac{3t^2}{5}x.
    $$

     中的斜率，两个数组都趋向于零，如 $t\to0$。这与 $x^2$ 和 $x^3$ 在 $0$ 的泰勒  linear  近似值相匹配，两者均为零。该代码正在读取上一节中限制局部 least-squares 的想法。


<a id="act-u7-code-quadratic-feature-matrix"></a>

**活动 7.4.5：二次  feature   matrix （U7-LO2、U7-LO4、U7-LO5）**

考虑代码：


```python
A2 = np.column_stack([np.ones_like(xs), xs, xs**2])
c2 = np.linalg.lstsq(A2, y, rcond=None)[0]
fit2 = A2 @ c2
r2 = y - fit2

A2.shape, c2, A2.T @ r2
```


1. $A2$的 columns 代表什么多项式 subspace ？

2. $c2$存储什么？

3. $fit2$存储什么？

4. `A2.T @ r2` 检查什么？

5. 为什么`A2.T @ r2`中有3个条目？

??? success "解答"

    $A2$的 columns 代表在`xs`中的点采样的

    $$
    \operatorname{span}\{1,x,x^2\}=\mathcal P_{\le2}
    $$

    vector  $c2$ 存储采样的  least-squares  二次方 

    $$
    c_0+c_1x+c_2x^2.
    $$

     的  coefficients   vector  `fit2` 存储样本点处的拟合值。  vector  `r2` 存储采样的 residuals 。计算 `A2.T @ r2` 检查每个采样的  feature   column  的  residual  是否为  orthogonal ： 

    $$
    \sum_i r_i=0,
              \qquad
              \sum_i x_ir_i=0,
              \qquad
              \sum_i x_i^2r_i=0.
    $$

     存在三个条目，因为近似值  subspace  有三个  feature   columns 。


<a id="act-u7-code-sampled-best-fit-plane"></a>

**活动 7.4.6：代码中采样的最佳拟合平面（U7-LO4、U7-LO5）**

考虑代码：


```python
grid = np.linspace(-1, 1, 5)
X, Y = np.meshgrid(grid, grid)

xx = X.ravel()
yy = Y.ravel()

z = 1 + 2*xx - yy + xx**2 + xx*yy + 2*yy**2 + xx**3

A = np.column_stack([np.ones_like(xx), xx, yy])
c = np.linalg.lstsq(A, z, rcond=None)[0]
r = z - A @ c

c, A.T @ r
```

假设输出大约为


```python
(array([ 2.5 ,  2.85, -1.  ]), array([0., 0., 0.]))
```


1. 使用了多少个采样点？

2. $A$ 三个 columns 代表什么？

3. coefficient vector 代表什么平面？

4. $A^T\mathbf r\approx\mathbf0$ 检查什么？

5. 这是采样线拟合的双变量版本如何？

??? success "解答"

    网格有$5\cdot5=25$个采样点。 $A$的三个 columns 分别是采样常数 feature 、采样$x$- feature 、采样$y$- feature 。  coefficient vector  表示采样的最佳拟合平面 

    $$
    q_{\mathrm{sample}}(x,y)=\frac52+\frac{57}{20}x-y.
    $$

     检查 $A^T\mathbf r\approx\mathbf0$ 表示 

    $$
    \sum_i r_i=0,
              \qquad
              \sum_i x_ir_i=0,
              \qquad
              \sum_i y_ir_i=0.
    $$

     这与采样线拟合的  residual - orthogonality  条件相同，但现在近似值  subspace  为 

    $$
    \operatorname{span}\{1,x,y\}.
    $$
