学习目标：U4-LO1、U4-LO2。


### Nicholson 5.3.3(b) {#exercise-nicholson-5-3-3-b}

在每种情况下，证明$B$是$\mathbb{R}^3$的 orthogonal basis ，并使用定理5.3.6将$\mathbf{x} = (a, b, c)$展开为 basis  vectors 的 linear combination 。

**(b)**

$$
B = \{(1, 0, -1), (1, 4, 1), (2, -1, 2)\}
$$


!!! info "题面引用说明"

    题面引用的展开公式：若 $B=\{\mathbf b_1,\ldots,\mathbf b_k\}$ 是 orthogonal basis，则 $\mathbf x=\sum_i\frac{\mathbf x\cdot\mathbf b_i}{\mathbf b_i\cdot\mathbf b_i}\mathbf b_i$。


### Nicholson 5.3.6(b) {#exercise-nicholson-5-3-6-b}

**(b)**

$$
\| 2\mathbf{x} + 7\mathbf{y}\|
$$


### Nicholson 5.3.9 {#exercise-nicholson-5-3-9}

设 $A$ 是一个 $m \times n$ 的  matrix ，它的各个  columns  组成  orthonormal  set。证明 $A^{T}A = I_{n}$。提示：若 $\mathbf{c}_{1}, \mathbf{c}_{2}, \dots, \mathbf{c}_{n}$ 是 $A$ 的各个  columns ，证明 $A^{T}A$ 的第 $j$ 个  column  的元素依次为 

$$
\mathbf{c}_{1}\cdot \mathbf{c}_{j}, \mathbf{c}_{2}\cdot \mathbf{c}_{j}, \dots, \mathbf{c}_{n}\cdot \mathbf{c}_{j}
$$

**练习 4.6.1：orthogonal coordinate 与 projection**

设


$$
\mathbf{q}_1
            =
            \frac{1}{\sqrt{2}}
            \begin{bmatrix}
            1\\
            1\\
            0
            \end{bmatrix},
            \qquad
            \mathbf{q}_2
            =
            \frac{1}{\sqrt{2}}
            \begin{bmatrix}
            1\\
            -1\\
            0
            \end{bmatrix},
$$


$$
Q
            =
            \begin{bmatrix}
            \mathbf{q}_1&\mathbf{q}_2
            \end{bmatrix},
            \qquad
            \mathbf{x}
            =
            \begin{bmatrix}
            3\\
            1\\
            2
            \end{bmatrix}.
$$


以“[ projection 与 residual ](4-2.md#fig-u4-projection-residual)”作为几何参考。


1. 检查


    $$
    Q^TQ=I_2.
    $$


2. 计算 coordinate vector 


    $$
    \mathbf{c}=Q^T\mathbf{x}.
    $$


3. 计算


    $$
    \widehat{\mathbf{x}}=Q\mathbf{c}.
    $$


4. 计算 residual 


    $$
    \mathbf{r}
                    =
                    \mathbf{x}-\widehat{\mathbf{x}}.
    $$


5. 检查


    $$
    Q^T\mathbf{r}=\mathbf{0}.
    $$


6. 解释计算如何遵循“先评分，再组合”的模式。

7. 哪个 vector 是 $\mathbf{x}$ 的 projection：$\mathbf{c}$ 还是 $\widehat{\mathbf{x}}$？


学习目标：U4-LO1、U4-LO3。


<a id="act-u4-review-gram-schmidt-step"></a>

**练习 4.6.2：Gram–Schmidt 的一个 column 计算**

假设第一个已构造的单位方向为


$$
\mathbf{q}_1
            =
            \frac{1}{\sqrt{2}}
            \begin{bmatrix}
            1\\
            1\\
            0
            \end{bmatrix},
$$


下一个原始列为


$$
\mathbf{a}_2
            =
            \begin{bmatrix}
            2\\
            0\\
            1
            \end{bmatrix}.
$$


使用 [Gram–Schmidt 算法](4-2.md#alg-u4-gram-schmidt)。


1. 计算


    $$
    r_{12}
                    =
                    \mathbf{q}_1^T\mathbf{a}_2.
    $$


2. 计算


    $$
    \mathbf{p}_2
                    =
                    r_{12}\mathbf{q}_1.
    $$


3. 计算


    $$
    \mathbf{v}_2
                    =
                    \mathbf{a}_2-\mathbf{p}_2.
    $$


4. 计算


    $$
    r_{22}
                    =
                    \|\mathbf{v}_2\|.
    $$


5. 计算


    $$
    \mathbf{q}_2
                    =
                    \frac{\mathbf{v}_2}{r_{22}}.
    $$


6. 检查


    $$
    \mathbf{q}_1^T\mathbf{q}_2=0.
    $$


7. $r_{22}=0$ 说明 $\mathbf{a}_2$ 具有什么性质？


学习目标：U4-LO2、U4-LO6。

<a id="ex-u4-code-residual-orthogonality"></a>

**练习 4.6.9：代码解读：residual orthogonality**

用“[ least squares 与 normal equations ](4-3.md#thm-normal-equations-residual-orthogonality)”解读下面的计算。


```python
import numpy as np

A = np.array([
    [1.0, 0.0],
    [0.0, 1.0],
    [1.0, 1.0],
])
b = np.array([2.0, 1.0, 5.0])

xhat = np.linalg.lstsq(A, b, rcond=None)[0]
bhat = A @ xhat
r = b - bhat
orthogonality = A.T @ r

xhat, bhat, r, orthogonality, np.linalg.norm(r)
```

假设最后两个输出约为


```python
array([1.3e-15, -2.2e-16])
```

以及


```python
1.1547005383792515
```


1. `[0]` 从 `np.linalg.lstsq` 的返回值中选择什么？

2. `xhat` 保存什么数学对象？

3. `bhat` 保存什么数学对象？

4. `r` 保存什么数学对象？

5. `A.T @ r` 检查什么几何条件？

6. 为什么 `orthogonality` 的各 component 极小，却不恰好为零？

7. residual norm 非零是否表示 least squares 失败？


学习目标：U4-LO4、U4-LO5、U4-LO7。

<a id="ex-u4-qr-code-reading"></a>

**练习 4.6.12：$QR$  least squares 代码解读**

用“[用 least squares 求解](4-4.md#alg-u4-qr-least-squares)”解读下面的代码。


```python
import numpy as np

A = np.array([
    [1.0, 0.0],
    [0.0, 1.0],
    [1.0, 1.0],
])
b = np.array([2.0, 1.0, 5.0])

Q, R = np.linalg.qr(A, mode="reduced")

x_qr = np.linalg.solve(R, Q.T @ b)
x_lstsq = np.linalg.lstsq(A, b, rcond=None)[0]

(
    Q.shape,
    R.shape,
    np.allclose(Q.T @ Q, np.eye(Q.shape[1])),
    np.allclose(Q @ R, A),
    x_qr,
    x_lstsq,
    np.allclose(x_qr, x_lstsq),
)
```


1. 为什么代码要求 `mode="reduced"`？

2. `Q` 与 `R` 的形状应是什么？

3. 下面的表达式


    ```python
    np.allclose(Q.T @ Q, np.eye(Q.shape[1]))
    ```

    检查什么？

4. 下面的表达式


    ```python
    np.allclose(Q @ R, A)
    ```

    检查什么？

5. 下面的表达式求解什么数学方程组？


    ```python
    np.linalg.solve(R, Q.T @ b)
    ```

    ?

6. 为什么 `x_qr` 与 `x_lstsq` 应一致？

7. 两者一致是否意味着


    $$
    A\mathbf{x}=\mathbf{b}
    $$


    有精确解？

8. 为什么 `Q`、`R` 的元素可能与手算 Gram–Schmidt 的符号不同？
